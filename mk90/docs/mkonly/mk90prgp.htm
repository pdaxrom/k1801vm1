Programator modułu pamięci RAM od mikrokomputera Elektronika MK-90

Odczyt i zapis modułu pamięci RAM jest możliwy za pomocą prostego układu podłączonego do portu równoległego komputera PC. Napięcie zasilające +5V można podciągnąć z portu klawiatury, myszy PS2 lub portu USB.

Podobne urządzenie, ale sterowane przez port USB zaprojektował Ilya Danilov - SMPReaderUSB.

Schemat programatora

Nadają się dowolne typy tranzystorów npn małej mocy, np. BC547.

Software

Program jest równie prosty jak układ.

mk90prog.zip - rozmiar pliku: 18kB, tekst źródłowy i kod wykonywalny

Wymagania

  • komputer PC z systemem DOS lub Windows 95/98/ME
  • port równoległy pod adresem 0x0378 pracujący w trybie SPP

Program nie będzie działał pod Windows 2000, NT, XP, ponieważ te systemy nie zezwalają na bezpośredni dostęp do sprzętu przez programy użytkownika.

Sposób użycia

Podłączyć moduł pamięci, załączyć zasilanie +5V a następnie uruchomić jeden z poniższych programów:

  • READ.COM - odczytuje pamięć modułu do pliku binarnego MK90.BIN
  • WRITE.COM - zapisuje plik binarny MK90.BIN do pamięci modułu
