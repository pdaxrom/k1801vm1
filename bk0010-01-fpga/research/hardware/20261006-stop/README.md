# СТОП БК и отсутствующие пультовые регистры, 2026-10-06

После прошивки keyboard hotfix оператор подтвердил: Esc останавливает
музыку на последнем тоне и замораживает строку заставки.
Это отдельная ошибка CPU/шины после исправления decoder.

[Книга Зальцмана](https://gid.pdp-11.net/books/Zaltsman.html) описывает
реальный путь: IRQ1 пытается записать PSW в отсутствующий 177676;
тайм-аут шины отправляет CPU в вектор 4. СТОП/HALT устанавливает
177716[2], который читается со сбросом. Предыдущая шина подтверждала
несуществующий регистр и позволяла VM1 читать пультовый вектор 160002
из ПЗУ дискового контроллера, где находятся команды, а не адрес/PSW.

`bk_cpu` теперь удерживает отсутствие ответа внутри CPU domain, не
передавая такую транзакцию в CDC. Сам неизменённый VM1 обрабатывает
тайм-аут. Нажатие Esc защёлкивается до попытки пультового сохранения;
удержание/повторные make без break не создают новых СТОП. Признак HALT
сохраняется до чтения 177716, с удержанием значения на всё время STB.

`tb_stop` проверяет семь штатных частот, СТОП внутри IRQ100 при PSW=340,
удержание 120 мс, короткое нажатие, HALT, RTI и сохранность SP, два чтения
признака причины. Прежняя прошитая версия CPU не проходит первый режим;
исправленная проходит все семь. Журналы — stop-native-before.log и
stop-native-all-rates.log; простой начальный probe также сохранён.

Diamond: 6747/6864 LUT, 3410/3432 slices, 2588 FF, 25/26 EBR.
Все ограничения выполнены, setup/hold без ошибок. Полный SoC прошёл
SD/BASIC, PRINT 2+2 по PS/2, семь частот, PAL без underrun, тёплый сброс
и возврат в BIOS с Backspace. Экран запуска/PRINT (по 16384 байта) и
32768 байт ROM побайтно совпадают с C.

Полная симуляция прежней прошивки воспроизвела ошибку: после физического
Esc make, удержания 120 мс и break, затем ещё 400 мс CPU остаётся на
PC=001102/PSW=0; SD reads=498, AY writes=110, SD writes=0. После 100
фактических записей AY предварительно нажаты и отпущены A/B, затем Esc.
Лог и SRAM сохранены отдельно. Исправленная версия после Esc загрузила DOS-Shell: 1598 чтений SD,
0 записей, video=041400, scroll=001336. Все 16384 байта активного RAM page 5
побайтно совпали с C-эталоном; SHA-256
`1cee183af1bff3233828af5a7c1978f930dca9f59f182641eeee91a9d9622080`.
CPU — native 24 МГц; механика КНГМД не ускорялась. ВМ1 исполнил BIOS,
ПЗУ и ОС, input пришёл через настоящий PS/2 transport и keymap. Показания
и хеши — native-validation.json, журнал — system-stop-after.log.

Flash записана и проверена за 56 секунд на Linux-стенде uJ11, JTAG ID
подтвердил LCMXO2-7000HC; UART дошёл до B:FF без ошибок. Порт закрыт
и независимо проверен как свободный. SD не записывалась, файлы FAT16
совпадают с предыдущим выпуском. Сводка — hardware-programming.json,
журналы — flash-session/. Ручная проверка Esc/DOS-Shell ожидается.
