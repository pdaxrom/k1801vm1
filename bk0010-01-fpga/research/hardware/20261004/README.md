# Первый аппаратный запуск БК0010-01

Историческая сессия. После неё [загрузчик БК переименован в LOADERBK.BIN](../20261004-loaderbk/README.md),
а исходный LOADER.BIN Пълдина восстановлен на карте.

4 октября 2026 года, Linux `sash@192.168.1.108`, плата hardware-lcd.
JTAG подтвердил LCMXO2-7000HC; Flash прошита операцией
`FLASH Erase,Program,Verify` в Diamond Programmer 3.14.
Программатор завершил проверку без ошибок за 54 секунды.

Использован [JED из релиза](../../../releases/hardware-lcd-20261004/design.jed),
SHA-256 `93aad47380391be38ab09874a7e598cc9d5f943542f16bbec8d5d19ba7881836`,
fuse checksum `069B`. [Лог программатора](flash-session-02/02-program.log),
[stdout](flash-session-02/02-program-stdout.log),
[XCF](flash-session-02/02-program.xcf), [UART](flash-session-02/uart.bin),
[сессия](flash-session-02/session.json), [результаты](result.json).

Первый запуск без SD передал `B:01`, `E:22`: карта в это время находилась
в кардридере. После её установки и длинного RESET UART передал:

```text
B:01
B:02
B:03
B:04
B:05
B:06
B:07
B:FF
```

Это подтверждает инициализацию SD, FAT16, загрузку native LOADER.BIN,
запись 32 КиБ ПЗУ в SRAM, CRC32 потока и независимого чтения SRAM,
ROM lock и передачу управления MONIT. Пользователь сообщил:
«sd rom 02, потом загрузился в бейсик». PAL показал этап загрузки и BASIC.
`SD ROM 02` обозначает этап чтения разметки, а не ошибку.

SD — `/dev/disk/by-id/usb-Generic_MassStorageClass_000000001210-0:2`,
7,4 ГиБ. Первый раздел: FAT16, type 06, LBA 2048, 32768 секторов,
512 байт/сектор, один сектор/кластер, 512 root entries.
Сохранены MBR и полный исходный раздел; файлы добавлены сначала в копию
раздела, затем выполнены запись и полная сверка чтения.
MBR и расположение остальных разделов сохранены.

Существующие P601.ROM/P601A.ROM/P601.CFG/P601.SET сохранены.
Прежний 481-байтовый LOADER.BIN Пълдина сохранён как LDRP601.BAK.
Новый LOADER.BIN — 337 байт, BK0010.ROM — 33280 байт.
[Отчёт записи SD](sd-written.json) содержит SHA-256 всех исходных и новых файлов.
Имеющееся расхождение метки `P601 BOOT` с отсутствующей меткой root
подтверждено одинаковым до и после изменения; новых замечаний FAT нет.

Полные резервные образы находятся на Linux в
`/home/sash/Work/FPGA/bk0010-hardware-20261004-01/`:
`sd-before.mbr`, `sd-before-fat16.img`, `sd-readback-fat16.img`.
Для возврата карты Пълдину нужно восстановить его LOADER.BIN из LDRP601.BAK.

Пользователь подтвердил ручную проверку: PS/2 `PRINT 2+2` возвращает `4`,
индикатор проходит 03 → 06 → 12 → 24 → 03, BASIC выполняет команду на каждой
частоте, изображение стабильно, длинный RESET возвращает BASIC.
Точная формулировка задания и ответ «да работает» записаны в result.json.
UART закрыт после проверки; функциональный аппаратный запуск пройден.
Измерение уровней PAL и калибровка скорости относительно реальной БК
пока не выполнялись. JTAG ID не определяет speed/temperature suffix FPGA.
