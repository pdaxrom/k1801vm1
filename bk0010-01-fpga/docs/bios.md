# BIOS БК и разделы SD

BIOS выполняется ВМ1 из resident EBR; выбранные рабочие ПЗУ ему не нужны.
Экран 32×16 с удвоенным шрифтом помещается в проверенное окно PAL.

При действительном `BK.SET` начинается отсчёт 10 секунд. Enter запускает
сразу, **Backspace** открывает настройки. Стрелка во время отсчёта тоже
открывает меню и сразу выполняет своё действие; автозагрузка прекращается.
Раннее нажатие сохраняется до чтения клавиши BIOS. Неверный или отсутствующий BK.SET открывает меню
с режимом 2, частотой 3 МГц и MONO. Ошибка SD выводится в меню.

Стрелки вверх/вниз выбирают одну из десяти строк; влево/вправо меняют значение:
модель, CPU FREQ, VIDEO, DRIVE A/B/C/D, SAVE AND BOOT, BOOT WITHOUT SAVE,
EXIT AND BOOT. В строке привода выбирается OFF либо PART 2…6 и RO/RW.
Недоступные выбранной модели приводы выключены. А16М допускает A/B;
стандартный КНГМД режима 3 — A/B/C/D. Первичные разделы 2…4 и два логических раздела 5/6 позволяют
назначить до четырёх разных дисков; расширенный раздел 4 пропускается в меню.

SAVE AND BOOT проверяет значения, записывает и перечитывает BK.SET,
затем запускает модель. BOOT WITHOUT SAVE применяет значения временно.
EXIT AND BOOT и Esc восстанавливают исходные значения. Ошибка сохранения
возвращает меню, сохраняет редактируемые значения и не блокирует ПЗУ.

| Ошибка hex | Причина |
|---|---|
| 50 | SD недоступна для сохранения |
| 51 | Недопустимые настройки |
| 52 | CMD24/CRC/timeout записи |
| 53 | BK.SET имеет атрибут read-only |
| 54 | Некорректные метаданные файла/FAT |
| 55 | Нет свободного root entry или кластера |
| 56 | Прочитанные после записи данные не совпали |

BK.SET — 16 байт, little-endian:

| Offset | Размер | Поле |
|---|---|---|
| 0 | 8 | `BKBIOS\0\0` |
| 8 | 1 | версия 1 |
| 9 | 1 | модель 0…4 |
| 10 | 1 | биты 0…2: индекс `3/4/6/8/12/16/24`; бит 3: COLOR |
| 11 | 1 | номера разделов A/B, младший/старший nibble |
| 12 | 1 | номера разделов C/D |
| 13 | 1 | защита записи A…D в битах 0…3 |
| 14 | 2 | CRC16-CCITT первых 14 байт, полином 1021h, начальное 0 |

Номер 0 отключает привод; 2…4 обозначают первичные разделы MBR, 5/6 — логические в расширенном разделе 4. Раздел 1
защищён. При изменении модели BIOS устанавливает её штатную частоту
(3 МГц для 0–2, 4 МГц для 3–4) и допустимые начальные назначения дисков.
На карте с двумя логическими дисками модель 0 получает A=5/B=6 RO,
модель 3 — A=6/B=5 RO. Настройки не содержат LBA: границы берутся
из MBR, EBR и CSD карты. Расширенный раздел допускается только в записи 4
с типом 05/0F/85. BIOS читает первые два EBR и допускает корректную ссылку
после второго на разделы других компьютеров, например TERAK 7/8.
Проверяются подписи прочитанных EBR, длины, переполнения, границы контейнера
и движение ссылок за предыдущий диск; ссылки назад запрещены.

Загрузочный раздел 1 — FAT16 06/0E. В его корне `LOADERBK.BIN`,
`BK00.ROM`…`BK04.ROM`, `BK.SET`; `LOADER.BIN/P601.SET` принадлежат Пълдину.
При обновлении существующего BK.SET BIOS сохраняет остальные 496 байт сектора.
При создании проверяет свободный кластер в обеих FAT, пишет и проверяет
данные, обновляет FAT и публикует root entry последним. Успех не меняет
посторонние файлы, разметку или дисковые разделы.

Дисковые разделы содержат непосредственно секторы диска БК. Рабочий
контроллер не обращается к файлам FAT и не подключает файлы образов дискет.
Адрес сектора: `base_LBA + ((track*2 + side)*10) + sector - 1`,
track 0…79, side 0/1, sector 1…10. Минимум 1600 секторов = 819200 байт;
хвост более крупного раздела остаётся вне доступной геометрии. Пустой,
короткий, пересекающийся с другим разделом или выходящий за SD раздел
не подключается. Дескрипторы блокируются после передачи управления.

Короткая кнопка меняет текущую частоту. Тёплый RESET (около 2 секунд)
сохраняет модель/ПЗУ/диски и возвращает стартовую частоту из BIOS.
RESET около 10 секунд вызывает полную повторную загрузку BIOS; Backspace
во время отсчёта открывает меню. Контроллер сначала завершает запись дорожки.

Подготовка файлов: `make build`, затем `python3 tools/prepare_sd_files.py`.
Для смонтированной карты используйте `--destination <каталог> --replace`:
обновляются только собственные loader/ROM БК, существующий BK.SET сохраняется.
Создание или форматирование физических разделов этим инструментом не выполняется.
