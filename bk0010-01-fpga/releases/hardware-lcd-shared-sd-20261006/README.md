# BIOS БК: общая SD с TERAK, 2026-10-06

JED `bk-shared-sd-2a29.jed`, checksum 2A29, для LCMXO2-7000HC-4TG144I.
Flash подключённой платы записана и проверена программатором за 57 секунд.
UART освобождён. После установки записанной общей SD оператор подтвердил
загрузку DOS-Shell; результат — `physical-bk-test.json`. UART-журнал этого
перезапуска не получен из-за переподключения FTDI. E:22/E:11 в первом
журнале относятся к запуску до установки SD.

BIOS БК отображает первые два логических раздела 5/6. Корректная ссылка
после второго EBR теперь разрешена, поэтому разделы TERAK 7/8 не мешают БК.
Границы дисков и ссылок, типы, переполнения и пересечения проверяются.
Последующие EBR БК не читает и в меню не отображает.

В RTL-симуляции прошли загрузка, сохранение BK.SET и тёплый reset на
первичных дисках и на цепочке 5 → 6 → 7 → 8. Конфигурация TERAK, остальные
файлы FAT16 и данные дисков сохранились. Точная копия рабочей SD прошла
загрузку BIOS до передачи управления ПЗУ с проверкой SRAM CRC.
15 повреждённых цепочек отклонены. Декодер Python прошёл четыре проверки.
4096 слов нового BIOS проверены в синтезированной памяти моделями Lattice.

Diamond MAP/PAR/TRACE: 6747/6864 LUT, 2588 FF, 25/26 EBR, 0 setup/hold ошибок.
BIOS занимает 7778/8192 байт. Из входов синтеза поменялся только boot.hex.
Остальные периферийные модули совпадают с hardware-lcd-bios-ps2-20261006;
их прежние проверки сохранены в том выпуске. Полная регрессия не повторялась.

LOADERBK.BIN и пять ROM bundles прежние. Для этой правки файлы БК на SD
заменять не требуется; сохраняйте BK.SET, диски БК и файлы Пълдина.
Предыдущий JED для восстановления доступен в
../hardware-lcd-bios-ps2-20261006/bk0010_impl1.jed.
Отчёты и границы проверки — qualification.json, checks/ и flash-session/.
