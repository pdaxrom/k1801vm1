# БК с AY: исправление PS/2 — 6 октября 2026

Esc — физическая клавиша Esc PS/2-клавиатуры, СТОП в рабочем БК.
При непрочитанном регистре символа прежний decoder блокировал Esc и
отпускания. Теперь рабочий режим продолжает обработку scan frames,
игнорируя лишние символы при занятом регистре; очередь BIOS сохраняется.
Единственный изменённый исходник итоговой FPGA — `rtl/bk_keymap.v`.

Исходный прошитый decoder воспроизводит ошибку в отрицательном контроле.
Проверены PS/2 make/break, модификаторы, очередь BIOS и 20 непрочитанных
клавиш. Transport/decoder/CSR всех пяти моделей сохраняют первый символ,
принимают Esc, не копят старый ввод и восстанавливают IRQ274.
Полный SoC прошёл SD/BASIC, PS/2 PRINT 2+2, семь частот, PAL,
тёплый сброс и Backspace BIOS. Экран и ROM совпали с C-эталоном.
Память итогового EDIF проверена на официальных моделях Lattice.
Другие функциональные отчёты сохраняют прежние снимки исходников.

LCMXO2-7000HC-4TG144I; Diamond 3.14 на Linux-стенде uJ11:
6769/6864 LUT, 3418/3432 slices, 2585 FF, 25/26 EBR. Все сети разведены,
setup/hold без ошибок. fMAX: CPU 29.914 ≥ 24 МГц, аудио 61.229 ≥ 48,
PAL 68.343 ≥ 64. JED, SHA-256, отчёты и логи — manifest.json и checks/.

BIOS, LOADERBK.BIN, ПЗУ, BK.SET и разделы SD не менялись. Для обновления
с предыдущей AY-прошивки SD переписывать не нужно. `sd-files/` оставлен
для подготовки другой карты; на рабочей карте сохраняйте BK.SET,
LOADER.BIN и P601.SET. Начальная конфигурация в комплекте — режим 2
без дисков; рабочая общая SD использует свою конфигурацию режима 3.

Ручная проверка Esc на дисковой заставке фиксируется отдельно.

Эта версия записана во Flash hardware-lcd на Linux-стенде uJ11.
FLASH Erase,Program,Verify завершился без ошибок за 56 секунд;
UART прошёл B:01/02/03/10/04/05/06/07/FF без E:xx. Порт освобождён.
SD не записывалась. Ручной результат Esc/DOS-Shell пока не получен.
