# Исправление клавиш BIOS БК, hardware-lcd

Первая стрелка во время десятисекундной автозагрузки теперь открывает
меню и сразу выполняет действие. Backspace открывает настройки, Enter
при отсчёте запускает сохранённый режим. Стрелки в меню выбирают строку
и меняют значение; для запуска — BOOT WITHOUT SAVE или SAVE AND BOOT.

Flash записана и проверена на Linux-стенде uJ11 за 57 секунд. UART B:11
подтвердил вход в BIOS, затем B:FF — выбранную загрузку, ошибок нет.
Оператор подтвердил работу меню и загрузку выбранного BASIC. UART освобождён.
JED SHA-256: `a305c323a39e677e398c1ac0abd9a09e5d1c2d7c5f24a92373fde2fa357364ce`.

Из routed inputs изменился только boot.hex. Runtime CPU/PS2/СТОП/AY/FDD/PAL
и все SD-файлы прежние. При этом обновлении SD не переписывалась, копировать
sd-files/ на рабочую карту не нужно. Сохраняйте BK.SET, Пълдин LOADER.BIN,
P601.SET и существующие сырые дисковые разделы.

15 групп проверок прошли. Новый BIOS проверен через native VM1, реальные
PS/2 кадры и SRAM: вход на 3 МГц, первая стрелка на 3/24 МГц, пять моделей,
четыре стрелки, частота/видео, Enter и загрузка режима 2. Тестовая SD
побайтно сохранилась. Проверены save/readback и ошибка RO=53; файлы Пълдина
сохранились. Diamond MAP/PAR/TRACE и синтезированные EBR прошли проверку;
6747/6864 LUT, 3410/3432 slices, 25/26 EBR, 0 setup/hold ошибок.
Проверка всех пяти моделей и сохранения настроек на плате ещё требуется.
