# БК с AY-3-8910, hardware-lcd — 5 октября 2026

Пять моделей, BIOS, КНГМД с сырыми разделами SD и AY на порту 177714.
Три голоса, шум и 16 форм огибающей; фиксированная частота 1,7734 МГц.
AY смешивается с бипером, моносигнал выходит на оба аудиовыхода платы.
Прошивка для LCMXO2-7000HC-4TG144I.

JED прошёл MAP/PAR/TRACE в Diamond 3.14 на Linux-стенде uJ11:
6758/6864 LUT, 3410/3432 slices, 2584 FF, 25/26 EBR. Все сигналы
разведены, setup/hold без ошибок. fMAX: CPU 28.294 ≥ 24 МГц,
аудио 58.741 ≥ 48 МГц, PAL 72.181 ≥ 64 МГц. Свободно 22 slices.

AY сверялся с независимой Python-моделью на 213520 тактах. Проверены
все формы огибающей, шум, нулевые и предельные периоды, протокол БК,
FIFO на семи частотах, ожидание диска, сброс и цифровой микшер/ЦАП.
Исправлена инструкция RESET: видеорегистр и прокрутка сохраняются,
снимается ожидающий IRQ, следующий кадровый IRQ100 разрешён. Это необходимо
для AY-плеера дисковой заставки. Проверены byte-записи и модель/lock для
всех пяти моделей; прежняя семантика воспроизводит ошибку в отдельном тесте.
Полный SoC прошёл BASIC, PS/2 PRINT 2+2, семь частот, PAL без underrun,
тёплый сброс и возврат в BIOS. ПЗУ и буферы итогового EDIF проверены
на официальных моделях Lattice. Отчёты и логи — checks/; SHA-256 и
состав — manifest.json. Предыдущие проверки сохраняют свои снимки исходников.

Музыкальная заставка BK0011M-System загружена настоящим ВМ1 из раздела SD
через BIOS/КНГМД/SPI со штатными задержками: 554 записи AY за секунду,
48000 отсчётов, 52 уровня PCM. Отчёт и [WAV](checks/native-music/ay-music.wav)
сохранены в checks/native-music/. Это цифровая симуляция звука.

JED SHA-256: `ef60ab649605631f65b948b4ab9ebc8b9a1ba9f349953b190572ebc1da5cd257`.

AY не меняет resident BIOS, LOADERBK.BIN, BK00.ROM…BK04.ROM или BK.SET.
Если SD уже подготовлена для версии models-disks-20261005, повторное
копирование не требуется. На общей карте начальные значения сохранены:
модель 3, 4 МГц, MONO, A=6 RO (System), B=5 RO (MK-DOS), C/D=OFF.
Разделы Пълдина 2/3 и его файлы остаются на карте.

sd-files/ предназначен для подготовки другой карты. Скопируйте файлы
в корень FAT16 раздела 1, сохраняя существующий BK.SET, LOADER.BIN и
P601.SET. Включённый BK.SET — заводской режим 2, 3 МГц, MONO без дисков.
Диски БК находятся в сырых разделах MBR 2…4 либо логических 5/6
в расширенном разделе 4; контейнер 4 приводом не назначается.
На общей SD БК использует 5/6, каждый по 1600 секторов.

Эта версия записана во Flash hardware-lcd через Linux-стенд uJ11.
FLASH Erase,Program,Verify прошёл успешно за 56 секунд. UART дошёл до
B:FF без E:xx: загрузка ПЗУ, CRC32 потока/чтения SRAM и ROM lock прошли.
[Журналы](../../research/hardware/20261005-ay/flash-session/session.json).
SD не переписывалась. Владелец подтвердил музыку AY на плате; звук есть при
неполной вставке TRS-штекера. Контакт/распиновка гнезда требуют проверки.
Аппаратно остаются бипер, звук при полной вставке штекера, проверка пяти моделей,
сохранения BIOS, обеих ОС и семи частот.

данные проверки — [20261005-ay](../../research/hardware/20261005-ay/README.md).
