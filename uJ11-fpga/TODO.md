# uJ11 TODO

Актуально на 2026-09-26.

Сверено с результатами **CP82** и программным обновлением **modules-v4**.
На плате подтверждены FPGA `hc1200-clock-calibrated` (CP67b с делителем KW11),
ODT с динамическим поиском FPP, программный FPP J‑11 CP80,
FIS/FPU BASIC и отключение/возврат FPP через cold boot.
[Версии, файлы и размещение во FRAM](docs/software.md).
HG TIME, калибровка KW11 и пониженная яркость установлены; CLOCK 01.01
через FRUN проверен на плате вместе с background-консолью и UJMOD.
Выход и UNLOAD F возвращают все 1007 слов занятой памяти.
[Проверки foreground CLOCK](releases/hg/foreground.json).

**Закрыто программно 2026-09-26, без изменения FPGA:**

- [x] [Готовая SD с RT-11FB](docs/sd-image.md): все текущие утилиты, CLOCK.SAV/REL,
  FRAM-модули, четыре BASIC и справка для `TYPE` прямо на диске.
  Воспроизводимая сборка, SHA256, native RT-11 и полный SPI RTL boot.
- [x] `ONn` в UJMOD 04.00: checksum сохранённого образа, включение без BIN с SD,
  последующая самоинициализация. OFF/ON проверены с FIS/FPU BASIC на плате.
- [x] Relocatable ODT/SDBOOT/FPP: настоящие записи DEC LINK `/R`, поправки при
  загрузке и checksum размещённого кода. ODT находит FPP по вектору/таблице.
- [x] Полный учёт BSS/стеков и `имя AUTO`. Метаданные размещения защищены суммой
  и привязкой к образу; неизвестные размеры старых модулей обрабатываются
  консервативно. На плате FPP автоматически размещён по `042710`.
- [x] `UJBOOT.SAV`: программный перезапуск через штатный bootstrap, без кнопки
  RESET и без перепрошивки. Три запуска на плате, восстановление модулей,
  BASIC и возврат CLOCK подтверждены.

[Формат, команды и загрузка](docs/modules.md),
[аппаратный отчёт и журналы](releases/software/module-update.json).
Свободно **34866 байт** основного HALT-пула; FPGA: прежние 36 LUT / 0 EBR / 19 uwords.

**Последующие улучшения:** программное ускорение FPP по SPI benchmarks;
RAW HALT/I/O в ODT, редактирование FP-регистров, десятичное FP-представление,
автоповтор клавиш/курсор и дополнительные RGB-состояния.
Аппаратные исследования — сокращение площади полного компьютера,
critical path памяти и отдельная оценка instruction-stream prefetch;
старые эксперименты CP52–56 не означают, что эти улучшения уже приняты.

**Отложено до перехода на другую FPGA:** MMU 18/22 и RT-11XM, processor register banks/mode SP/I-D,
обычный integer PSW `177776`, общий NXM→HALT assist и оставшиеся особенности
HALT ВМ2 (H/P, вложенные входы, SEL174/274). PSW-операнды программного FPP
уже реализованы в CP80. Аппаратный/микрокодный FP11 не является текущим планом.
Аппаратный запас текущей сборки — **36 LUT, 12 slices, 0 EBR, 19 uwords**;
На HC1200 эти функции больше не расширяем.

Дефекты эталонного общего `core/`, отмеченные CP70, относятся к отдельному
проекту; в uJ11 firmware их нет. В этой работе `core/` не меняется.
