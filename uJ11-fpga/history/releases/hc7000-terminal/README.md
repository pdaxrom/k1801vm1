# HC7000: зеркало консоли UART на PAL

> Историческая запись: `releases/hc7000-terminal/README.md`, Git `31549d1`.
> Прошивки и полные снимки исходников удалены из рабочего дерева; [восстановление](../README.md).


2026-10-01. JED **3428** для LCMXO2-7000HC-4TG144C / hardware-lcd / SRAM
IS61WV102416BLL-10T / внешний генератор 12 МГц.

MMU / SERV storage / FPP off / FIS / diagnostics / PAL / terminal.
Консоль DL11 сохраняет `177560..177566`, векторы `60/64` и UART 115200/8/N/1.
Принятые символы одновременно попадают в программный терминал SERV:
**640×240, 16 цветов, 80×30 символов**, одна страница. Ввод остаётся через UART.

**Установлена на плату 2026-10-01**, Flash Erase/Program/Verify прошли без ошибок.
Пользователь подтвердил нормальный текст загрузочного меню на PAL.
2.9BSD загрузилась с RL0, определила 1864384 байта доступной памяти,
перешла в multiuser и смонтировала `/usr` на XP0. Проверены вход root,
`ls /usr`, `/etc/fstab` и `sync`; плата оставлена на приглашении root.
Логи и подробности: [аппаратная проверка](validation/hardware-20261001/README.md).

MAP/PAR/TRACE прошли с ограничениями CPU/PAL, всех выводов SRAM и четырёх
CDC mailbox bundles; отрицательного slack нет. JED и все входы совпадают
с сохранённым manifest. SHA-256 JED:
`2c1691d770ec3e3508abbc7a203cd9ce72c892f2c433ff5e83337b599434a5e1`.

Проверены парсер VT100/VT52 (подмножество), FIFO, окно SRAM SERV,
защита framebuffer от CPU и DMA, порядок байтов, гостевой RESET,
прокрутка и PAL без underrun. Полные загрузки RT-11 V4, RT-11 XM,
RSX RQ1 и 2.9BSD сохранены в `validation`; в BSD выполнены запись/чтение
на RL и RP, удаление тестовых файлов и `sync`. Исходные образы не менялись.
RSX показывает устройства DU и каталог с `RSX11M.SYS`.

Загрузки выполнены на снимке RTL `terminal-pal-50-05`. Финальный `06`
отличается освобождением владельца DMA после NXM; для этой строки проведены
отдельные проверки ошибочного DMA и повторная проверка UART/PAL.
Каждый набор сохраняет собственные входные исходники и hashes.
Сборки SERV с выключенным терминалом, с PAL и без него, совпадают побайтно
с предыдущим выпуском. Production-проверка HC1200 проходит без изменений.
