# HC7000: оригинальный шрифт DEC VT52, JED E517

> Историческая запись: `releases/hc7000-terminal-vt52/README.md`, Git `31549d1`.
> Прошивки и полные снимки исходников удалены из рабочего дерева; [восстановление](../README.md).


2026-10-02. Сборка `terminal-vt52-50-01` установлена на физическую HC7000:
Flash Erase/Program/Verify прошли без ошибок. MMU / SERV storage / FPP off /
FIS / diagnostics / PAL / terminal, CPU 50 МГц, PAL 64 МГц от генератора 12 МГц.
LCMXO2-7000HC-4TG144C, SRAM IS61WV102416BLL-10T; PAL 640×240 / 80×30.

Вместо шрифта Pico 5×7 используется
[дамп знакогенератора настоящего DEC VT52](https://github.com/fritzm/vt52/blob/master/data/vt52rom.h),
[считанный Fritz Mueller](https://fritzm.github.io/vt52.html).
Сохранены семь колонок и восемь строк ROM, восьмая колонка ячейки пустая.
Порядок семи битов развёрнут под SERV: бит 0 — левый пиксель. Масштабирование
и изменение рисунка не применялись. Сохраняются 96 слотов ASCII 32..127,
768 байт констант и 3072 байта кеша масок SRAM. Лицензия MIT и атрибуция
сохранены в заголовке; исходный дамп и лицензия — в `validation/font/`.

## Ресурсы и проверки

| Показатель | Результат |
|---|---:|
| LUT / FF / EBR | 5897 / 2020 / 26 |
| Fmax CPU / PAL | 50,633 / 64,927 МГц |
| Код/константы SERV / BSS | 15067 / 1072 байта |
| Запас перед стеком / cold bank | 1652 / 512 байт |
| Резерв стека / максимум в UART/PAL | 640 / 240 байт |
| Текстовый режим | 80×30, ячейка 8×8 |

RTL и код SERV не менялись относительно
[C3DA](../hc7000-terminal-throughput/README.md). Двоичное сравнение подтвердило
изменение только 768 байт шрифта по смещению 13808; размер BSS и границы стека
совпали. MAP/PAR/TRACE прошли ограничения CPU 50 / PAL 64 МГц, SRAM и CDC.
Все исходники и отчёты сверены по SHA-256 перед прошивкой.

Хостовый тест парсера прошёл, в том числе с AddressSanitizer и
UndefinedBehaviorSanitizer. Реальный SERV/UART/PAL/SRAM в RTL прошёл
157928 проверок, 2187 байт провода и 12 отдельных сдвигов. Все колонки
35 строк каталога, включая блоки и даты, видны перед чтением CR.
Время потока сохранилось: 51160906 тактов / 1,023218 с.

## Физическая плата

Стенд `sash@192.168.1.108`, UART `/dev/ttyUSB1`, 115200 8N1.
Перед установкой плата ожидала ввода в 70Boot; ОС не была запущена.
Свежий завершённый read-only поиск `xp(0,0)unix` подтвердил возврат в
приглашение загрузчика. HG освободил JTAGENB и проверил высокий уровень.
Diamond подтвердил `FLASH Erase,Program,Verify` и `Operation: successful`.

Получено новое меню SD, автозагрузка RL0 отменена. Выбраны RH0 и RT-11 XM
V05.03. Полный DIR завершился за 7,416 с, его 6690 байт побайтно совпали с
C3DA: 214 файлов, 5346 блоков, 48310 свободных блоков. Проверка не меняла
SD-карту или образы дисков. Плата оставлена на приглашении RT-11;
`fuser` подтвердил освобождение UART. Внешний вид VT52 на физическом PAL
пока не подтверждён пользователем.

`validation/hardware/` содержит журнал прошивки, захват UART, состояние
сеанса и проверенный `result.json`; там же сохранены управляющий сценарий
и его зависимости. `sources/` содержит точные входные файлы синтеза;
`synthesis/` — манифест, отчёты и экспорт. `validation/uart-pal/` содержит
результаты RTL, эталонные байты шрифта и framebuffer.
