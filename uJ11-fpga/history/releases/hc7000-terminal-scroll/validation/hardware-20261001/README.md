# HC7000: аппаратная проверка JED 54D2

> Историческая запись: `releases/hc7000-terminal-scroll/validation/hardware-20261001/README.md`, Git `31549d1`.
> Прошивки и полные снимки исходников удалены из рабочего дерева; [восстановление](../../../README.md).


2026-10-01, Linux `sash@192.168.1.108`, UART `/dev/ttyUSB1`, 115200/8/N/1.
Драйвер единолично владел UART после закрытия picocom пользователем.
Linux ISTRIP удалял программный бит чётности BSD; `uart.bin` содержит именно
полученные драйвером байты, `uart.txt` — читаемый вариант без CR/NUL/DEL.

BSD перед прошивкой выполнила `sync`. Пользователь коротко нажал кнопку ODT;
свежее чтение R7 вернуло **004632**. Перед программированием проверены
контрольные суммы всех входов, JED и отчётов финального синтеза, устройство,
генератор 12 МГц и ограничения CPU 50 / PAL 64 МГц.

Diamond 3.14 выполнил **Flash Erase/Program/Verify за 57 секунд**, без ошибок.
Установлена JED **54D2**, SHA-256
`2c331872a2fbd9f66a108b553607b9d45edbf3e9482a30f3f8cb2bfd33a72f37`.
Свежий SD boot menu захвачен, автозагрузка отменена, выбраны RL0 и
`rl(0,0)rlunix`.

2.9BSD сообщила `mem = 1864384`, подключила RL0 и XP0, перешла по Ctrl+D
в multiuser и смонтировала `/usr` на `/dev/xp0h`. Проверены вход root,
`stty nl0 cr0`, `ls -l /usr`, шесть отдельных переводов строки и `sync`.
После каждой команды получено приглашение `#`; ошибок UART/драйвера нет.
Сообщения init об отсутствии `/dev/tty00..07` относятся к оставленной
конфигурации будущих DZ-терминалов и сохранены в захвате.

**Визуальное подтверждение исправленной прокрутки пока ожидается.**
Цифровые стенды отдельно подтверждают шесть последовательных сдвигов,
порядок очистки/рисования и отсутствие underrun. Аппаратный захват UART
подтверждает прошивку и работу BSD, но не измеряет аналоговое изображение PAL.

UART закрыт после последнего `sync`; BSD оставлена на приглашении root,
picocom можно снова открыть. `session-01/session.json` сохраняет исходную
запись владельца UART; итог отдельно проверенных этапов находится в
`result.json`, без общего утверждения об успешной визуальной проверке.
Драйвер, его зависимости, programmer XCF, логи Flash/Verify и сырой захват
сохранены рядом и включены в общий `SHA256SUMS` выпуска.
