# HC7000: PS/2-клавиатура, JED 347F

> Историческая запись: `releases/hc7000-ps2/README.md`, Git `31549d1`.
> Прошивки и полные снимки исходников удалены из рабочего дерева; [восстановление](../README.md).


2026-10-02. Подготовлена для LCMXO2-7000HC-4TG144C / hardware-lcd с SRAM
IS61WV102416BLL-10T. MMU / SERV storage / FPP off / FIS / diagnostics /
PAL 640×240 / VT52 font / PS/2 keyboard. CPU 50 МГц, PAL 64 МГц, генератор 12 МГц.
347F прошла физическую FLASH Erase/Program/Verify, приняла ввод PS/2 и
загрузила RT-11 XM, но DIR/SHOW CONFIGURATION вернули ошибку чтения оверлея.
Для диагностики временно восстановлена E517; исправление и повторная
проверка 347F продолжаются. Эту попытку нельзя считать успешной
аппаратной квалификацией дисков.

Кадры PS/2 принимает небольшой аппаратный блок; сканкоды переводит SERV.
ASCII и управляющие последовательности поступают в прежний DL11 RBUF,
включая прерывание с вектором 60. UART сохраняется; дополнительного PDP TTY нет.
Подробные подключения, клавиши и ограничения — [руководство PS/2](../../../docs/hc7000-ps2.md).
В том числе: питание разъёма 3,3 В, английская раскладка, индикаторы клавиатуры
пока не синхронизируются, мышь пока не обслуживается.

| Показатель | Значение |
|---|---:|
| LUT / FF | 6046 / 2098, +149 / +78 относительно E517 |
| Свободные LUT | 818 / 6864 |
| EBR / PLL | 26 / 2, без изменения |
| Fmax CPU / PAL | 50,123 / 65,733 МГц |
| Код/константы SERV / BSS | 16363 / 1084 байта |
| Запас перед стеком / cold bank | 344 / 512 байт |
| Резерв стека | 640 байт |

MAP/PAR/TRACE прошли частоты 50/64 МГц, SRAM и CDC. Сохранены точные входы
синтеза, прошивка SERV, JED, отчёты и журналы функциональных проверок.
`design.jed`: checksum **347F**, SHA-256
`36a20b0f4fb5b089ccfcff5d90810d80f4fa7ca4ee3959af3225a077c0e3598a`.

Проверки:

- Хост: модификаторы, повтор, отпускание, Ctrl/NUL, VT52/VT100/PF, keypad,
  Pause/Print Screen, ошибки и ожидание свободного приёмника.
- Приёмник: 24 проверки физических кадров, фильтра, parity, stop, timeout,
  очереди, торможения CLOCK минимум на 100 мкс и сброса.
- Реальный SERV + PS/2 + UART + DL11: 39 принятых байт, вектор 60,
  совместный ввод, заполнение очереди, сохранение порядка и гостевой RESET;
  максимум записанного стека 240/640 байт.
- Реальный SERV/UART/PAL: 158842 проверки, 2187 байт провода, 12 отдельных
  сдвигов; все колонки 35 строк DIR видны до CR. 55234697 тактов / 1,104693 с
  против 1,023218 с у E517 (+7,96% в этом тесте вывода); стек 224/640 байт.
- RK05/MSCP: 1075994 проверки с тем же бинарным SERV, быстрым SRAM и PAL,
  включая DMA/IRQ/ошибки; стек 336/640 байт. Проверка границ инструкций
  берёт размер кода из ELF, вместо устаревшей константы 13 КиБ.
- Отключённая клавиатура: бинарная прошивка SERV побайтово совпадает с E517.
  Production-проверка HC1200 подтвердила идентичность прежних RTL/EBR/ROM и ПО.

Пользователь подтвердил физический ввод `dir` с PS/2-клавиатуры, принятый
системной консолью. На контрольной E517 с той же SD проверены RT-11 XM
(полный DIR и SHOW CONFIGURATION), V4 (DIR и V4USER.TXT), RSX с RQ1
(DU0/DU1 и каталог с RSX11M.SYS, 1026 блоков), BSD с RL0 (multiuser/root,
каталог `/usr` с XP0 и `/etc/fstab`). RSX штатно остановлена через SHUTUP,
BSD выполнила sync. Позднее на этой же E517 чтение RL0 закончилось
`cs=110315` и `panic: IO err in swap`: длительная работа BSD не прошла
проверку. Журналы первой попытки и контрольных загрузок —
`validation/hardware/`. Последующий повтор 347F ещё не завершён.

Конфигурация не создаёт
ответы идентификации терминала; при одновременной работе с UART их по-прежнему
отправляет подключённый к UART терминал.

`sources/` хранит входы по исходным путям; `sources/generated/` — сгенерированные
ограничения и команды синтеза. `validation/` содержит результаты и журналы.
Все сохранённые файлы проверяются по `SHA256SUMS`.
