# Ресурсы и timing

Установленная аппаратная версия — CP67b. Реструктуризация 2026-09-22
не меняет её RTL/EBR по коду и содержимое ROM; новый synthesis не выдаётся
за выполненный. Для новых изменений использовать `make synthesis`.

| Показатель | Результат MAP/PAR/TRACE |
|---|---:|
| LUT | 1244 / 1280 |
| FF | 381 |
| EBR | 7 / 7 |
| Slices | 628 / 640 |
| Fmax TRACE | 32,032 MHz |
| OSCH nominal | 29,56 MHz |
| Timing constraint с FRAM budgets | 31,824 MHz |
| Microstore | 1005 / 1024 × 36 |

Запас: 36 LUT, 12 slices, 0 EBR, 19 микрокоманд. Первоначальная цель
900–1100 LUT не достигнута для полного компьютера с периферией.

[Исходные отчёты и manifest](../releases/hc1200/result.json),
[прошитый JED](../releases/hc1200/design.jed),
[его SHA256](../releases/hc1200/jed.json).
Файлы выпуска сохранены побайтно; старые пути внутри manifest — происхождение
релиза, не входы текущей сборки. `verify_production.py` проверяет архив,
соответствие нового RTL/ROM и пересобранных модулей этому baseline.

FPP, ODT и BASIC исполняются во внешней FRAM и не добавляют LUT/FF/EBR.
Аппаратный PSW-прототип не поместился: 649/643/648 slices при лимите 640;
эти варианты не прошивались. MMU также остаётся отдельным экспериментом.
