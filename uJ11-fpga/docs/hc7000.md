# uJ11: HC7000 / hardware-lcd

Ветка `uJ11-hc7000`, исходная ревизия HC1200
`13db2b9d21c6be637132c9321723e3f56542d378`. Профиль `hc7000-lcd-sram`
предназначен для **LCMXO2-7000HC-4TG144C**, внешнего генератора **12 МГц**
и **IS61WV102416BLL-10T**. Плата описана в Z-pdaXrom-TV, ревизия
`98cfd1311acb`, `docs/hardware/generated/hardware-lcd-pins.csv`.

## Частоты и память

PLL: CLKI_DIV=1, CLKFB_DIV=2, CLKOP_DIV=20, обратная связь CLKOP.
PFD=12 МГц, VCO=480 МГц, система=24 МГц. Второй выход CLKOS=30 МГц
сохранён в сгенерированном SCUBA модуле, но не подключён к логике.
Попытка 30 МГц не прошла TRACE; первой рабочей частотой выбраны 24 МГц.

- UART: 115200, 8N1; делитель 208, фактически 115384,6 бод (+0,16%).
- KW11-L: 50 Гц, TICK_DIVISOR=480000.
- SD SPI: 200 кГц при инициализации, 6 МГц после неё.
- Кнопка: период debounce 20 мс. Короткое нажатие HALT с входом в ODT,
  длинное RESET. Оба действия проверены пользователем на плате 2026-09-27.

CPU и ABI совпадают с HC1200: USER/HALT по 64 КиБ, MMU нет. SRAM word
address = `{4'b0, bank, address[15:1]}`; DMA RK обращается в USER.
ROM overlays и служебные физические обращения сохраняют прежнюю семантику.
Из физического чипа 2 МиБ CPU сейчас использует **128 КиБ**.

После конфигурации или потери PLL LOCK контроллер очищает эти 128 КиБ,
удерживая CPU в reset. Обычный RESET, PDP-11 RESET и UJBOOT память
не очищают. RESET во время обмена отменяет ответ, но завершает импульс
записи и hold time. При повторном включении питания или перепрошивке
нужно снова установить модули с SD.

SRAM: один такт setup, два access, отдельные hold/release. Управление,
адрес и выходные данные регистрируются. В `sram-timing.lpf` заданы
launch ≤10 нс для адреса/control, ≤15 нс для DQ/tri-state, read input delay
22 нс (FPGA 10 + SRAM 10 + предполагаемые 2 нс платы). Это консервативная
проверка за один такт; реальные фазы длиннее. 2 нс платы — расчётное
допущение, не измерение осциллографом. TRACE проверяет setup и hold всех
SRAM data/address/control; UART и асинхронные входы HG не имеют внешнего
синхронного timing-контракта. SD работает тем же SPI RTL, что и HC1200.

Физический пульт отсутствует. CSR 166000/166001 сохранён для HG, строки
клавиатуры маскируются до включения HG output-enable. После его снятия
SELECT остаётся видимым до реального освобождения хостом: это необходимо
для многоблочных запросов старого HG.SYS. Flash CS/WP/HOLD
удерживаются в 1; видео, звук и индикаторы выключены.

## Сборка

Все команды выполняются из `uJ11-fpga`. Значение BOARD по умолчанию — HC1200.
RTL `boards/hc1200`, CPU, микрокод и firmware остаются прежними.

HC7000 теперь использует автономный RK611 на SERV с секторным DMA. Архитектура,
RISC-V toolchain, проверки и ресурсы описаны в [hc7000-rk611-iop.md](hc7000-rk611-iop.md).
Прежняя сборка HC1200 сохраняет RKSERV на основном CPU.

```sh
make hardware BOARD=hc7000-lcd-sram
make test-sram
make test-hc7000-hg
make test-rt11 BOARD=hc7000-lcd-sram OUT=build/hc7000-rt11
make synthesis BOARD=hc7000-lcd-sram OUT=build/hc7000-build
make export BOARD=hc7000-lcd-sram OUT=build/hc7000-build
python3 tools/make_programmer_xcf.py \
  build/hc7000-build/impl1/hc7000-build_impl1.jed \
  build/hc7000-build/program.xcf --board hc7000-lcd-sram
```

Нужны прежние native RT-11 assembly prerequisites; synthesis/export выполняются
в Linux с Diamond 3.14. Для повторных прогонов используйте новый OUT.
Генерируемые HDL HC7000 находятся в `build/hc7000-hardware/`.
Экспорт сверяет исходники и отчёты по SHA-256 и требует успешных MAP/PAR/TRACE.
Проверка PLL выбирает Fmax системного `clk`, но учитывает negative slack
из **всего** отчёта, включая внешнюю SRAM.

`make test`, `test-basic`, `test-configuration`, `verify` — прежние проверки
HC1200. Последние два явно отклоняют BOARD=hc7000-lcd-sram; тест удержанного
FRAM-образа нельзя считать тестом начального состояния SRAM.

## Стенд и первый запуск

Стенд: `sash@192.168.1.108`, UART `/dev/ttyUSB1`. Изолированный каталог
порта: `/home/sash/Work/FPGA/uj11-hc7000-port-20260927`.
Старая SD от HC1200 загружается без замены образа.

После power-on выполнить в RT-11:

```text
RUN UJMOD
ODT
RUN UJMOD
SDBOOT
RUN UJMOD
FP11 AUTO
RUN UJBOOT
```

Каждый RUN UJMOD ждёт приглашения `UJMOD>`. После UJBOOT STATUS показывает
140407 у трёх установленных модулей. Используются BIN/SAV со старой SD.

Проверки платы с сохранением UART-транскриптов:

```sh
python3 tools/hardware_hc7000.py --phase modules --out build/board-modules
python3 tools/hardware_hc7000.py --phase basic --out build/board-basic
python3 tools/hardware_hc7000.py --phase odt --out build/board-odt
```

Фаза modules предназначена только для пустой SRAM сразу после конфигурации.
Она проверяет пустую таблицу перед установкой. BASIC запускает имеющиеся
B81FIJ/B81FPU/B81FPD; ODT использует ODTCHK.SAV, проверяя AC2, STEP и CONTINUE.

## HG / JTAGENB

Перемычка: **FT2232D ADBUS7 pin 16 → R22 pad 1 / FPGA pin 120**.
R22 10 кОм к 3,3 В сохраняется. `JTAG_PORT=DISABLE` позволяет JTAGENB
выбирать JTAG при 1 и пользовательские I/O при 0.

```sh
../lsi11-fpga/host/hg/hgfsd --directory /path/to/hg-volume --jtag-enable-adbus7
# Завершить daemon через SIGINT/SIGTERM перед Programmer.
../lsi11-fpga/host/hg/hgfsd --jtag-only
```

При запуске HG ADBUS7 становится выходом 0. При завершении daemon — входом
high-Z; подтяжка возвращает JTAGENB в 1. Оба уровня проверяются чтением FTDI.
`--jtag-only` восстанавливает JTAG и выходит без дискового образа.
Без новых опций hgfsd сохраняет поведение HC1200. Одновременная работа HG
и Programmer через канал A не поддерживается. После SIGKILL сначала выполнить
`--jtag-only`; штатная обработка сигнала не может выполниться при SIGKILL.

Фаза `--phase hg` требует запущенного daemon с отдельным writable-каталогом,
содержащим HELLO.TXT со строкой `HC7000 SD SRAM HG ROUNDTRIP`. Она проверяет
HGTIME и ход часов, затем копирует файл через свободное имя SY:U7TEST.TXT
обратно в HG:BACK.TXT и удаляет только созданный тестовый файл SD.
После остановки daemon нужно отдельно сравнить BACK.TXT с HELLO.TXT,
учитывая нулевое дополнение до RT-11 блока.

## Ограничения первого порта

Сохранены 16-битная карта CPU и ручная загрузка модулей после power-on.
Полный аппаратный тест всех 2 МиБ, UART ESC recovery на плате
и измерение сигналов осциллографом остаются отдельными этапами.
Модель SRAM проверяет старшие адреса, но это не заменяет тест всего чипа
на плате. Подробные результаты первого запуска — в `releases/hc7000/`.
