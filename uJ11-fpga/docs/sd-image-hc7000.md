# SD-комплект RT-11XM для HC7000

Этот комплект — **raw RK07 для `IOP=legacy`**, с FPP BASIC и без таблицы
разделов. Он сохраняет конфигурацию своего выпуска 2026-09-27 на 24 МГц.
Установленная **7CBA** использует `IOP=storage`, FPP off, PAL и PS/2:
на её SD находятся несколько ОС и диски компиляторов.
[Текущее меню и назначение дисков](boot-validation.md),
[формат разделов и утилита](serv-storage.md).
Готовый единый образ всех ОС с HGX/HGTIME:
[HC7000 multi-OS](../releases/sd-hc7000-multi/README.md).
Raw-образ ниже нельзя записывать с LBA 0 на эту карту как обновление:
он заменит таблицу разделов и существующие диски. `B81FPU/B81FPD` требуют FPP;
для текущей карты проверен `RUN BAS:BASIC`, затем выбор `A`.

Готовый образ: [`uj11-hc7000-rt11xm.img.gz`](../releases/sd-hc7000/uj11-hc7000-rt11xm.img.gz).
Это отдельный комплект для `BOARD=hc7000-lcd-sram CPU=mmu`: SRAM 2 МиБ,
генератор 12 МГц, система 24 МГц. Нужна прошивка с исправлением режима
TRAP, например [сборка 08](../history/releases/hc7000-mmu-trap-fix/README.md).

Образ сразу загружает `DM0:RT11XM (S) V05.03`. Состав:

- `HGX.SYS` — драйвер HG для XM; имя устройства остаётся `HG:`.
- `HGTIME.SAV`, `HGSYNC.COM` — установка системных даты и времени с хоста.
- `B81FPU.SAV`, `B81FPD.SAV` — BASIC single/double; `B81TST.BAS`, `B81DBL.BAS` — проверки.
- `TMRATE.SAV` — диагностика системного таймера; `XMCHK.COM` — конфигурация и память.
- Исходники `HGX.MAC`, `HGTIME.MAC`, `TMDRV.MAC`, `TMRATE.MAC`.
- Справка на диске: `README`, `BASIC`, `ODT`, `MEMORY`, `TIMER`, `HOST`, `FILES`, `BUILD` (`.TXT`).
- Исходные DEC MACRO, LINK, EDIT, PIP, DUP, BINCOM, HELP, библиотеки, мониторы и драйверы.

`STARTX.COM` выключает SL и выводит справку. Начать можно с `TYPE README.TXT`,
`@XMCHK` и `RUN B81FPU`; на вопрос BASIC ответить `A`, затем `RUN B81TST`.
Числовой тест должен дать 29 проверок без ошибок. `PRINT 1/0` возвращает READY,
следующий `PRINT 2+2` печатает 4. Для double также выполнить `RUN B81DBL`.

Старые HALT-модули, UJMOD/UJBOOT и приложения HDSP в XM-комплект не входят.
FPP и ODT находятся в микрокоде FPGA; команды нового ODT описаны в `ODT.TXT`.
[Образ HC1200/FB](sd-image.md), его сборщик, драйвер HG и утилиты сохранены.

## HG и системные часы

На Linux-стенде:

```sh
make -C lsi11-fpga/host/hg
lsi11-fpga/host/hg/hgfsd --directory /path/to/shared --jtag-enable-adbus7
```

Каталог должен быть выделен для обмена с RT-11. Перемычка ADBUS7 порта A
FT2232 соединяет его с JTAGENB, pin 120/R22. Сервис опускает JTAGENB для HG
и освобождает при завершении; перед программированием FPGA остановить сервис.
`hgfsd --jtag-only` возвращает JTAGENB в высокий уровень.

В RT-11:

```text
@HGSYNC
DATE
TIME
DIR HG:
COPY HG:HELLO.TXT SY:HELLO1.TXT
COPY SY:HELLO1.TXT HG:BACK.TXT
```

`@HGSYNC` выполняет `LOAD HG` и `RUN HGTIME`. Дата и время берутся из локального
часового пояса Linux-хоста и устанавливаются через `.SDTTM`. При ошибке связи,
контрольной суммы или некорректном времени системные часы не меняются.
Автозапуск не обращается к хосту: SD загружается и при выключенном `hgfsd`.

XM находит `HGX.SYS` при загрузке. Если драйвер скопирован на работающую SD
после загрузки, перед `LOAD HG` нужен `INSTALL HG` или перезагрузка.
Имена новых файлов в примере должны быть свободны. Файлы на стороне хоста
дополняются нулями до границы блока 512 байт. HG выгружает записи из своего
образа в каталог после короткого периода простоя; тест ожидает завершения.

`HGX.MAC` — отдельный исходник. Он задаёт `MMG$T=1`, а байты буфера передаёт
через `$GTBYT`/`$PTBYT` монитора, включая продвижение PAR на границе отображения.
Контракт служб описан в [DEC RT-11 Device Handlers Manual, §1.10.4](https://bitsavers.trailing-edge.com/pdf/dec/pdp11/rt11/v5.6_Aug91/AA-PE7VA-TC_RT-11_Device_Handlers_Manual_Aug91.pdf).
Сборка использует макробиблиотеку именно V5.03 и проверяется с монитором V5.03.
Протокол HG и хостовая программа не меняются. `HGTIME` и `TMDRV` используют
прежние исходники; прошивку FPGA для HGX менять не требуется.

## Распаковка и запись

Это raw RK07: 53 790 секторов, 27 540 480 байт, без MBR/FAT. На Linux:

```sh
cd uJ11-fpga/releases/sd-hc7000
gzip -dk uj11-hc7000-rt11xm.img.gz
sha256sum -c SHA256SUMS
```

Записывать весь `.img` с LBA 0 на выбранную SD, предварительно сохранив её
данные и размонтировав разделы. Устройство в примере — заполнитель:

```sh
sudo dd if=uj11-hc7000-rt11xm.img of=/dev/SD_DEVICE bs=4M conv=fsync status=progress
```

Запись образа стирает прежнюю файловую систему SD. Сам сборщик открывает
только новые обычные файлы. При подготовке релиза физическая SD целиком
не перезаписывалась; на неё отдельно добавлен и проверен `HGX.SYS`.

## Воспроизведение

Из `uJ11-fpga`, для каждого запуска — свежий выходной каталог:

```sh
make BOARD=hc7000-lcd-sram CPU=mmu sd-image
make BOARD=hc7000-lcd-sram CPU=mmu test-sd-image
make BOARD=hc7000-lcd-sram CPU=mmu test-hg-time
```

Можно задать `SD_OUT`, `SD_TEST_OUT`, `HG_OUT`, `HG_TEST_OUT`. Без `CPU=mmu`
эти цели продолжают собирать прежний комплект HC1200/FB.
Нужны Python, SIMH `pdp11`, `lsi11/rt11tool`; для RTL — Verilator и зависимости
[MMU-сборки](hc7000-mmu.md). HGX и утилиты собираются оригинальными MACRO/LINK
в отдельной копии FB-диска. `COPY/BOOT` создаёт загрузочные блоки XM.
В конечный образ попадают только эти блоки, утилиты и справка; изменения
SWAP.SYS и другие записи рабочей симуляции не переносятся.

Сборщик проверяет SHA-256 исходного FB-диска, BASIC и собранных программ,
геометрию/каталог, обратное извлечение всех добавленных файлов, сохранность
исходных DEC-файлов, home block и последних 66 зарезервированных секторов.
Заменяется только `STARTX.COM`; `STARTF.COM` остаётся исходным. Даты новых
файлов фиксированы, свободные блоки обнулены, gzip не содержит времени сборки.
Контрольные суммы и входы сохранены в `manifest.json`.

Проверки готового комплекта и HG: [`releases/sd-hc7000`](../releases/sd-hc7000/README.md).
SIMH проверяет загрузку XM на 11/73 с 2 МиБ, справку, BASIC с исключениями,
таймер, запись/чтение SD и VM. Полная RTL-модель исполняет тот же образ через
реальные модели SD/SERV/SRAM/UART. HG в SIMH проверяется с явно выделенной
подменой GPIO, а настоящий драйвер и FT2232 — на HC7000.
