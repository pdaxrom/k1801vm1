# Текущий комплект uJ11

Документация сверена 2026-09-26. FPGA — **hc1200-clock-calibrated**
(CP67b с калибровкой KW11); в этом обновлении FPGA/RTL/микрокод/ROM не менялись.
MMU отключён. Микрокодный FIS независим от программного FPP.

Программный комплект **modules-v4**: UJMOD **04.00**, relocatable ODT/SDBOOT/FPP
и UJBOOT **01.00**. ODT сохраняет пульт, автоскроллинг и ток HCMS `0x6C`,
но теперь находит перемещённый FPP по таблице и активному вектору.
Математика FPP — прежняя J‑11 **CP80 / 00.12**, включая PSW-операнды.
Изменились формат файла и размещение, а не модель арифметики.

## Готовые файлы

Полный [образ SD](sd-image.md) объединяет этот комплект с HG, CLOCK.SAV/REL,
демонстрациями пульта, четырьмя BASIC и диагностикой. На диске есть
самостоятельная справка по всем нашим утилитам: `TYPE SY:README.TXT`.

| Назначение | Файл | Размер файла |
|---|---|---:|
| Отладчик, UART и пульт, FP disassembly/dump | [ODT.BIN](../releases/software/ODT.BIN) | 15360 байт |
| Программный FPP DCJ11, включая PSW-операнды | [FP11.BIN](../releases/software/FP11.BIN) | 5632 байта |
| Заменяемый SD bootstrap | [SDBOOT.BIN](../releases/software/SDBOOT.BIN) | 1536 байт |
| Загрузчик/таблица модулей RT-11 | [UJMOD.SAV](../releases/software/UJMOD.SAV) | 5632 байта |
| Программный перезапуск с повторной инициализацией | [UJBOOT.SAV](../releases/software/UJBOOT.SAV) | 2048 байт |
| Общая FP-регрессия для RT-11/ODT, необязательна для загрузки | [FPTST.SAV](../releases/software/FPTST.SAV) | 1536 байт |

Размер BIN включает header, relocation records и padding SD. В HALT FRAM
хранятся только исправленный код и рабочая область. Полный размер BSS/стека
указан в заголовке и проверяется UJMOD; подробности — [формат модулей](modules.md).

`releases/software/manifest.json` фиксирует SHA256 и происхождение файлов.
Новые BIN требуют UJMOD 04.00: сначала обновить загрузчик на SD. Старые пакеты и журналы установки —
в [Git-истории](../history/README.md). Порядок установки — в [руководстве](user-guide.md).

## Размещение и STATUS

Все адреса, LENGTH и CHECKSUM в этой таблице восьмеричные; размеры в байтах
десятичные. Верхняя граница диапазонов включена.

| Модуль | BASE | LENGTH, слова | CHECKSUM | Полное размещение |
|---|---|---|---|---|
| ODT, пониженная яркость | 010000 | 014315 | 031761 | 010000–042707, 13768 байт |
| SDBOOT | 006000 | 000342 | 053365 | 452 байта внутри малого пула |
| FPP CP80, AUTO | 042710 | 004174 | 166644 | 042710–053715, 4614 байт |

Это установленная таблица платы: слоты 0, 1, 2. После инициализации у всех
STATUS `140407`. Номера определяются через `RUN UJMOD` → `STATUS`.
Команда `FP11` без AUTO по-прежнему использует preferred BASE `060000` и
checksum `142034`; такой пример в руководстве относится к размещению без AUTO.
Не нужно повторять его поверх уже перемещённого FPP: для временного возврата
использовать `ON2`, для новой установки — сначала удалить прежнюю запись.

ODT содержит 12698 байт immutable code/data и 1070 байт BSS/stack;
FPP — 4344 и 270 байт. После компактного размещения свободны
`053716..157777`: **34866 байт** основного HALT-пула. Малый пул имеет ещё
60 байт после SDBOOT. Sidecar в `007100..007277` учитывает полные диапазоны.

`OFFn` сохраняет код и allocation, `ONn` проверяет retained image и возвращает
AUTO без SD. Для применения конфигурации нужен длинный RESET без ESC либо
`RUN UJBOOT`. Программный перезапуск требует работающей RT-11 и завершённых
файловых операций, останавливает foreground-задачи; восстановление при зависании
по-прежнему выполняется кнопкой RESET + UART ESC. [Подробности](configuration.md).

## BASIC и проверки

На SD установлены [BASIC CP81 и тестовые программы](../demos/rt11/basic/README.md):

- FPP включён: `RUN B81FIJ` (FIS), `RUN B81FPU` (single), `RUN B81FPD` (double).
- FPP выключен и RT-11 перезагружена: работает также исходный `RUN B81FIS`.
- `B81FIJ` подходит для обеих конфигураций. Его 26-байтовый адаптер учитывает
  дополнительные слова стека .SFPA при наличии FPP.

Сборка и проверка текущего baseline из каталога `uJ11-fpga`:

```sh
make verify
```

Проверяются действующие RTL/ROM, пересобранные BIN/SAV и неизменность релизов.
Это локальная проверка, не новый аппаратный тест. [Остаток работ](../TODO.md).

## Обновление HG и часы

В дополнение к FRAM-модулям есть комплект
[HG.SYS 01.01, HGTIME.SAV и CLOCK.SAV/REL](host-time.md). Они устанавливают
системные дату/время RT-11 с хоста и показывают часы на HDSP. Готовые файлы
и manifest — в `releases/hg/`, исходники — в `demos/rt11/hostdisk/` и
`demos/rt11/panel/`. Комплект прошёл native RT-11, host tests и аппаратную
проверку синхронизации через UART с SHA256 обратных копий.
HG TIME впервые установлен 2026-09-22; foreground-вариант CLOCK.REL
добавлен 2026-09-26. `FRUN SY:CLOCK` оставляет background-консоль доступной;
[управление и проверки](host-time.md#часы-одновременно-с-командной-строкой-и-программами).
FPGA и модули в HALT FRAM не меняются.
