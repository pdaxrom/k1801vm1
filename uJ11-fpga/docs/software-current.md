# Текущий комплект uJ11

Документация сверена 2026-09-22. Последнее подтверждённое состояние платы —
[CP82 от 2026-09-20](modules-cp82.md): FPGA **CP67b**, ODT **CP77**,
программный FPP J‑11 **CP80 / 00.12**, SDBOOT и UJMOD **CP67**.
MMU отключён. Микрокодный FIS работает независимо от модуля FPP.

## Готовые файлы

| Назначение | Файл | Размер файла |
|---|---|---:|
| Отладчик, UART и пульт, FP disassembly/dump | [ODT.BIN](../demos/rt11/service/cp80/ODT.BIN) | 13312 байт |
| Программный FPP DCJ11, включая PSW-операнды | [FP11.BIN](../demos/rt11/service/cp80/FP11.BIN) | 5120 байт |
| Заменяемый SD bootstrap | [SDBOOT.BIN](../demos/rt11/service/cp67/SDBOOT.BIN) | 1024 байта |
| Загрузчик/таблица модулей RT-11 | [UJMOD.SAV](../demos/rt11/service/cp67/UJMOD.SAV) | 4608 байт |
| Общая FP-регрессия для RT-11/ODT, необязательна для загрузки | [FPTST.SAV](../demos/rt11/service/cp80/FPTST.SAV) | 1536 байт |

Размер BIN включает header и дополнение до блока SD; это не полный размер
модуля в HALT FRAM. BSS и стек задаются программой отдельно.

README и `release.json` внутри каталогов `service/cpNN` — замороженные
снимки выпуска, включённые в hashes. Их «ещё не установлен» и
`installed_on_board: false` относятся к моменту выпуска. Последующая
установка CP80 подтверждена [аппаратным журналом](board-fpp-cp80.md),
а повторное отключение/включение — [CP82](modules-cp82.md).
Для эксплуатации использовать эту страницу и [руководство](user-guide-cp67.md).

## Размещение и STATUS

Все адреса, LENGTH и CHECKSUM в этой таблице восьмеричные; размеры в байтах
десятичные. Верхняя граница диапазонов включена.

| Модуль | BASE | LENGTH, слова | CHECKSUM | Полное размещение |
|---|---|---|---|---|
| ODT CP77 | 010000 | 014233 | 134145 | 010000–042543, 13668 байт |
| SDBOOT | 006000 | 000342 | 053365 | 452 байта внутри пула 006000–006777 |
| FPP CP80 | 060000 | 004174 | 142034 | 060000–071005, 4614 байт |

В подтверждённой таблице платы это слоты 0, 1, 2; после обычного cold boot
у всех STATUS `140407`. Номера зависят от истории загрузок: определять их
через `RUN UJMOD` → `STATUS`. OFF/DEL/повторная установка требуют затем
длинного RESET; [проверенный порядок](modules-cp82.md).

ODT содержит 12598 байт immutable code/data и 1070 байт BSS/stack.
FPP содержит 4344 и 270 байт соответственно. До FPP остаётся промежуток
042544–057777 (6812 байт), после FPP — 071006–157777 (28154 байта).
UJMOD проверяет пересечение неизменяемых образов; полное размещение BSS
и стека нужно согласовывать отдельно. Автоматического allocator сейчас нет.
Образы абсолютные, relocation loader отсутствует.

## BASIC и проверки

На SD установлены [BASIC CP81 и тестовые программы](../demos/rt11/basic/README.md):

- FPP включён: `RUN B81FIJ` (FIS), `RUN B81FPU` (single), `RUN B81FPD` (double).
- FPP выключен и RT-11 перезагружена: работает также исходный `RUN B81FIS`.
- `B81FIJ` подходит для обеих конфигураций. Его 26-байтовый адаптер учитывает
  дополнительные слова стека .SFPA при наличии FPP.

Архивы можно проверить локально, без обращения к плате и повторной прошивки:

```sh
python3 uJ11-fpga/tools/verify_modules_cp67.py
python3 uJ11-fpga/tools/verify_cp80.py
python3 uJ11-fpga/tools/verify_cp80_hardware.py
python3 uJ11-fpga/tools/verify_basic_cp81.py
python3 uJ11-fpga/tools/verify_modules_cp82.py
```

Все пять проверок архивов выполнены 2026-09-22 — PASS. Команды проверяют
сохранённые свидетельства; это не новые аппаратные тесты.
