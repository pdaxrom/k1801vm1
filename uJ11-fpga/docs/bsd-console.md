# Медленная консоль 2.9BSD на HC7000

В образе `lsi11/disks/bsd2.9/2.9BSD-root.rl02` включены терминальные
флаги `nl2 cr2`: программные задержки после перевода строки и возврата
каретки. Они создают заметные паузы даже при выполнении простых команд.

В текущей консоли BSD выполните:

```sh
stty nl0 cr0
```

Проверить настройки можно командой `stty everything`. После изменения
в выводе не должно быть `nl2 cr2`. Настройка относится к текущему терминалу;
после нового входа или перезагрузки её может потребоваться повторить.
Для постоянного применения команду можно добавить в используемый файл
инициализации shell после входа. Однопользовательская консоль имеет
отдельную инициализацию и также требует этой настройки.

UART FPGA работает на **115200, 8N1**. Значение `300 baud`, показанное
`stty` после входа в этот образ BSD, не меняет фиксированную скорость UART.
Менять скорость терминальной программы на хосте не требуется.

Решение подтверждено пользователем на плате HC7000 2026-09-28. На частной
копии тех же дисков в SIMH повторные `ls` с одинаковым выводом занимали
3,378 секунды до изменения и 0,045–0,046 секунды после. Эти числа относятся
к SIMH и устранению задержек вывода, а не к ускорению CPU FPGA. Записи
`tty00`–`tty07` и будущие терминалы этим изменением не затрагиваются.
