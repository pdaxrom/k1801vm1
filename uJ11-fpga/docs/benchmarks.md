# Измерения производительности

Последующая [CP82](configuration.md) проверила смену конфигурации FPP,
исключения FIS и сохранность модулей. Её 582937544 clocks относятся ко всему
RTL-сценарию, не к новому benchmark производительности. FPGA CP67b и FPP
CP80 остались прежними; ниже сохранены измеренные результаты их этапов.

## BASIC-11 V2.1: измерения CP81

Полный RTL CP67b с SPI FRAM/SD, программный FPP CP80, обычного
memory-mapped PSW нет. Одинаковый B81TST дал 29 сравнений / 0 ошибок
в FIS single, FPU single и FPU double; последний дополнительно запускает
B81DBL для проверки младших разрядов.

| Сеанс | Clocks | FIS opcodes | FPP opcodes / HALT entries |
|---|---:|---:|---:|
| B81FIS + B81TST | 204015076 | 654 | 0 / 0 |
| B81FPU + B81TST | 364565396 | 0 | 4117 / 4117 |
| B81FPD + B81TST + B81DBL | 507545495 | 0 | 5782 / 5782 |

Это время от команды запуска BASIC до возврата BYE: включает SD,
инициализацию, ввод UART, программы и вывод. Не является CPI или чистым
временем математической библиотеки; у double ещё одна программа.
Весь стенд с загрузкой модулей и cold init: 1322444008 clocks, 22 проверки.
Все три сеанса обходятся без внешнего USER 177776. Новых LUT/FF/EBR нет,
Fmax не переизмерялся. [Результаты, программы и границы](basic.md).

Эти числа описывают успешную арифметику исходного BASIC. Его FIS-обработчик
ошибок потребовал адаптации к стеку RT-11 с активным FPP. Новый B81FIJ
прошёл полный RTL с исключениями (384497709 clocks / 17 checks) и UART
физической платы; этот отдельный сценарий не является сравнением скорости.

## PSW-операнды FPP: сравнение CP79/CP80

Сравнены 8512 zero-wait RAM samples на одинаковых vectors/partitions CP79:
CFCC 790→803 clocks, LDFPS (R2) 1234→1290, STF AC0,(R2) 1802→1867,
STCFI AC0,R5 8183→8212. Это конкретные samples, не SPI FRAM timings.
Проверка PSW добавляет программные инструкции и memory beats; числовые
алгоритмы прежние. FPGA CP67b неизменна. Полная RT‑11 интеграция:
**833104183 clocks / 9776 UART bytes / 99 checks PASS**; это весь
сценарий, включая UART/ODT и cold boot, не CPI отдельной FP-команды. [Детали и таблица](fpp-psw.md#накладные-расходы).


Полные старые таблицы AM4/microcpu и uJ11 сохранены в [истории](../history/README.md).
Числа clocks из интеграционных тестов не являются CPI CPU.
