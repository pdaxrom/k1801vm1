# CP66: установка ODT на плату, 2026-09-13

**CP66 установлен на SD, загружен в HALT FRAM и активирован.**
Использована согласованная пара из коммита `9acb06e`. FPGA остаётся CP63b:
перепрошивки, нового synthesis и дополнительных LUT/FF/EBR нет.
ODT с данными и стеком занимает 11746 из 12288 байт HALT FRAM.

## Файлы и обратное чтение

На `sash@192.168.1.108` переданы только ODT.BIN и UJON.SAV, **13312 байт**,
в `/tmp/uj11-cp66-install-20260913/share`. Проверенный HG daemon работал на
1000 Hz. RT-11 увидела ODT — 23 блока и UJON — 3 блока.

```text
LOAD HG
DIR HG:
COPY HG:ODT.BIN DK:ODT.BIN
COPY HG:UJON.SAV DK:UJON.SAV
COPY DK:ODT.BIN HG:ODCHK.BIN
COPY DK:UJON.SAV HG:ONCHK.SAV
UNLOAD HG
```

Каждая команда COPY завершилась приглашением RT-11. Обе обратные копии
побайтно равны исходным файлам из коммита и проверены по SHA256:

| Файл SD | Обратная копия | SHA256 |
|---|---|---|
| ODT.BIN | ODCHK.BIN | `54e765644c19fb52a9fdb5b5f2599294bdc6b92cf7ee1bda140faa3eab1460a2` |
| UJON.SAV | ONCHK.SAV | `feca40caabfe6af8ead1d098f6106125ca9df39b6997d17947e3858e05057c81` |

Образ SD целиком и существующий UJLOAD не заменялись. После UNLOAD HG созданный
daemon PID 163438 штатно завершён; пины пульта освобождены. Picocom PID 162709
приостанавливался только на время UART-операций и возобновлён; итоговое
состояние процесса и владение `/dev/ttyUSB1` проверены.

## Загрузка и включение

```text
RUN UJLOAD
UJLOAD> ODT
!UJLOAD-I-WRITING; target disabled
!UJLOAD-I-ODT READY
.
RUN UJON
!UJON-I-CP64 DEBUG ENABLED; SHORT RESET ENTERS ODT
.
```

`CP64` в ответе активатора — историческая строка шаблона. UJON собран для
точного CP66 и проверил его код в FRAM; это подтверждено SHA256 и успешным
выполнением активации. Баннер самого монитора — `UJ11 ODT CP66:`.

После короткого RESET должен открываться CP66; кнопка 9 вызывает новый STEP
OVER с обычными IRQ. P/Z/U доступны в UART и меню MEM. После cold boot/длинного
RESET вновь загрузить ODT через UJLOAD и выполнить UJON. Предыдущий сеанс точек
при cold reset не восстанавливается; отлаживаемую программу нужно загрузить
заново перед установкой точек.

## Что подтверждено на железе

Подтверждены запись файлов на SD, полное обратное чтение, ODT READY,
проверка загруженного кода активатором, включение debug и освобождение HG/UART.
На этом этапе нет подтверждения физического входа по кнопке и покомандной
проверки CP66 на пульте. Ранее подтверждённая пользователем работа CP65 и
RTL-тесты CP66 не подменяют эту проверку.
