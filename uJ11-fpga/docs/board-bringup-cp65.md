# CP65: обновление ODT на плате, 2026-09-13

**CP65 установлен на SD, загружен в HALT FRAM и активирован.**
Использована согласованная пара из коммита `2e776d3`. FPGA не перепрошивалась:
остаётся установленная CP63b, дополнительных LUT/FF/EBR нет.
Монитор с данными и стеком занимает 9902 из 12288 байт HALT FRAM.

## Передача и проверка

На `sash@192.168.1.108` переданы только `ODT.BIN` и `UJON.SAV`, всего 11264 байта.
HG работал на прежних проверенных 1000 Hz с отдельным каталогом
`/tmp/uj11-cp65-install-20260913/share`. RT-11 увидела 19 и 3 блока соответственно.
Штатные COPY записали оба файла на DK:, затем прочитали их обратно на HG:

| Файл на SD | Обратная копия | SHA256 совпал |
|---|---|---|
| ODT.BIN | ODCHK.BIN | `38c422ec519bb98f6eecb250480155df7edf0239c84f43027adbd1fb8e4ed740` |
| UJON.SAV | ONCHK.SAV | `e00a1022a0e5babb92050c28ebca62fdda93fbf407490d4bc6cdf63487350cbf` |

Каждая COPY вернула приглашение RT-11, сообщений об ошибках нет.
Образ SD целиком не заменялся; прежний UJLOAD не менялся.

После readback выполнен `UNLOAD HG`, daemon PID 159514 штатно завершён.
Общие пины освобождены для пульта. Пользовательский picocom PID 157550
временно приостанавливался вокруг UART-операций и возобновлён.

## Загрузка и активация

```text
RUN UJLOAD
UJLOAD> ODT
!UJLOAD-I-WRITING; target disabled
!UJLOAD-I-ODT READY
.
RUN UJON
!UJON-I-CP64 DEBUG ENABLED; SHORT RESET ENTERS ODT
.
```

Надпись `CP64` в последней строке сохранена в шаблоне активатора. Его
параметры проверки пересобраны для CP65: это подтверждают SHA256 активатора,
readback и успешная проверка загруженного кода. Баннер самого монитора —
`UJ11 ODT CP65:`.

Короткий RESET теперь должен входить в установленный CP65. После холодного
старта или длинного RESET снова выполнить `RUN UJLOAD`, ввести `ODT`, затем
`RUN UJON`; новая пара уже находится на SD.

## Граница аппаратной проверки

Установка, обратное чтение файлов, FRAM ready и включение debug подтверждены
реальной платой. После активации выполнялся 60-секундный пассивный UART capture;
нового входа по кнопке в нём нет. Автопрокрутка, клавиши 8–F и поведение
регистров на физическом пульте CP65 пока требуют подтверждения пользователя.
Ранее подтверждённые проверки пульта CP64 не выдаются за проверки CP65.
