# CP66: аппаратная проверка ODT через UART, 2026-09-13

**STEP, P/Z, RUN TO, STEP OVER, отмена коротким RESET и возврат в RT-11
прошли на физической плате.** FPGA остаётся CP63b, ODT — CP66.
RTL, микрокод и прошивка FPGA не менялись; новых измерений ресурсов нет.

Проверка выполнена через `/dev/ttyUSB1` на `sash@192.168.1.108`,
115200 baud, команды с интервалом 100 ms между символами. Исходная ревизия
проекта — `22235ca`; ODT/UJON — согласованная сборка `9acb06e`.
Это проверка UART-команд; меню и клавиши пульта в этом проходе не нажимались.

## Подготовка и отклонения

Использован точный `tb/reports/cp66/guest/UJTEST.SAV` из прежнего полного
RTL-прогона. Он скопирован на SD как `DK:U66TST.SAV`, без пересборки:
1536 байт, SHA256
`00dd4dd474e9ca528c4db80bafbe9250f0ff94cd5a5adf3775f02b835da4929a`.
Обратная копия `HG:TSTCHK.SAV` побайтно равна исходному файлу.

Первый HG-сеанс завершился ошибкой чтения каталога; файл тогда не был
установлен. После сообщения пользователя «HG подключено проверяй» повторные
DIR/COPY прошли. Причина первой ошибки не установлена. HG работал на 1000 Hz,
после `UNLOAD HG` созданный для теста daemon штатно остановлен.
Обратное COPY превысило 45-секундный таймаут UART helper; завершённый файл
проверен по SHA256, приглашение RT-11 подтверждено отдельной пустой командой.
Сеанс с таймаутом сохранён как незавершённый, а не переименован в успешный.

Первый `RUN UJON` сообщил `CP63 OR MATCHING VERIFIED ODT UNAVAILABLE`.
Причина не определялась по одному сообщению. Выполнены штатные
`RUN UJLOAD` → `ODT` → `RUN UJON`; получены `ODT READY` и `DEBUG ENABLED`.
Программа `RUN U66TST` запущена только после успешной активации.

## Результаты

Все числа в таблице, кроме количества срабатываний, восьмеричные.

| Сценарий | Наблюдаемый результат |
|---|---|
| Короткий RESET в тестовом цикле | ODT доступен; исходные R0/R2–R5 сохранены, R4=`125061`, SP=`177777`, PC=`001046`, PSW=`010344` |
| `S` на `INC R1` | R1: `0→1`, PC=`001050`, SP=`177777`; баннер `UJ11 ODT CP66: DEBUG` |
| `P 1046`, `C` | `BREAKPOINT`, PC=`001046`; исходное слово `005201` восстановлено, SP остаётся нечётным |
| `C` с PC на самой точке | R1: `1→2`; повторная остановка на `001046`, оригинал исполнен один раз |
| `Z 1046`, `P` | Точка снята, список пуст |
| `U 1054` | `RUN TO ADDRESS`, R1=`3`, PC=`001054`; исходный `BEQ` (`001774`) восстановлен |
| `T` на вложенном JSR (`001132`) | `OVER RETURN`, PC=`001136`, SP=`001000`; R0/R2/R3 увеличены на единицу |
| `T` на NOP | Один STEP, PC=`001140`, регистры и стек сохранены |
| `T` на вызове WAIT/KW11-L (`001160`) | `OVER RETURN`, PC=`001164`, SP=`001000`; счётчик обработчика по `001324` равен 1 |
| `T` на вызове RT-11 (`001326`) | LOOKUP/READW/CLOSE вернулись на `001332`, SP=`001000`; `DKOK=1`, прочитаны слова ODT.BIN `045125`, `030461` |
| `P 1132`, `U 1136`, короткий RESET | Возврат в ODT на PC=`001054`, SP=`177777`; оба слова `004767`/`000240` восстановлены, определение `P 1132` сохранено |
| `Z`, `W 1076 1`, `C` | `!UJTEST-I-CONTEXT RESUMED` и приглашение RT-11 |
| Повторный `RUN UJON` | Проверка кода ODT снова прошла; debug оставлен включённым |

Для подпрограмм SP был восстановлен из `OLDSP` по адресу `001074`:
на плате он равен `001000`. После вызовов сначала восстановлен исходный
PSW с IPL7, затем нечётный SP. Это необходимо для корректного возврата
в специально подготовленный цикл теста.

Пользователь подтвердил два коротких RESET сообщениями «нажал» и «готово».
Непосредственные баннеры этих двух входов не попали в ограниченные окна
пассивной записи. Подтверждение опирается на сообщения пользователя,
состояние RUN до нажатия и последующие UART-чтения остановленного контекста
и восстановленных команд. Баннеры автоматических остановок STEP/P/U/T
сохранены полностью. Это не измерение задержки RESET.

## Артефакты и оставшаяся проверка

[Сырые журналы, readback и manifest](../tb/reports/cp66-uart-hardware/verification.json)
сохранены отдельно от прежнего RTL-архива и журнала установки. Проверить:

```sh
python3 tb/reports/cp66-uart-hardware/verify_capture.py
```

Проверка сверяет 15 сценариев по фактическим UART-байтам и SHA256 артефактов.
Она не запускает новый аппаратный тест. На завершении UART свободен,
созданные HG daemon остановлены, плата находится в RT-11 с включённым ODT.
`U66TST.SAV` оставлен на SD для повторения теста.

Ещё не закрыты отдельный проход меню/клавиш пульта CP66, длинный RESET,
рекурсивный STEP OVER на железе, гостевой trace/BPT, ошибки записи патчей,
UART burst и измерение электрических таймингов FRAM. Их прежние RTL-проверки
не выдаются за результаты этого аппаратного сеанса.
