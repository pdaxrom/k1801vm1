# TERAK на HC7000: SD для первого аппаратного запуска

Полный образ в этом каталоге предназначен для отдельной карты.
Для существующей общей SD с дисками Пълдина и БК подготовлено
[добавление разделов TERAK 7/8](shared-sd/README.md).
Конфигурация общей карты находится в том каталоге; `TERAK.CFG` здесь
соответствует полному образу с дисками TERAK в разделах 2/3.

Образ подготовлен 2026-10-06, прошивка обновлена 2026-10-07. Образ побайтно совпадает с MBR-картой, на которой
проверена холодная загрузка UCSD Pascal II.0 до меню и ввод через PS/2.
Прошивка FPGA — **TERAK AE82**, CPU 50 МГц, монохромный PAL-60 (525/60),
BEVNT 60 Гц. AE82 записана и проверена во FLASH HC7000. На общей SD
оператор подтвердил полностью видимое меню UCSD и вход в Filer клавишей F.
Отдельный полный образ проверен в RTL-симуляции; физический запуск
выполнен с общей картой и TERAK в разделах 7/8.

## Состав

- `uj11-hc7000-terak.img`: полный образ MBR-карты, 19 922 944 байта
  (19 МиБ, 38 912 блоков по 512 байт).
- `uj11-hc7000-terak.img.gz`: сжатая копия того же образа.
- `terak-ae82.jed`: рабочая прошивка HC7000 с SERV, MBR/raw и видео 640×240.
- `terak-06b6.jed`: прежняя прошивка для восстановления.
- `checks/`, `flash-session/`: входы, отчёты Diamond, результаты моделирования и записи FPGA.
- `TERAK.CFG`: копия конфигурации, уже записанной в первый раздел образа.
- `manifest.json`, `qualification.json`, `SHA256SUMS`: состав и контрольные суммы.

| Раздел | Начальный LBA | Блоков | Содержимое |
|---|---:|---:|---|
| 1 | 2048 | 32768 | FAT16, `TERAK.CFG` |
| 2 | 34816 | 501 | unit 0: UCSD II.0, SSSD raw, чтение/запись |
| 3 | 36864 | 501 | unit 1: NASA DEM1, SSSD raw, чтение/запись |

Оба диска нужны этому комплекту UCSD при запуске. Все остальные приводы
выключены. Каждый raw-диск содержит 256 256 байт; последние 256 байт его
раздела — выравнивание до блока SD. Не следует копировать IMD или raw как
файлы в FAT16: данные дисков уже находятся непосредственно в разделах 2 и 3.

Используйте **SDHC/SDXC**: прошивка требует SD с блочной адресацией и CSD v2.
Оставшаяся часть большей карты не используется. Обычная прошивка uJ11
с таблицей UJ11SD не загрузит эту MBR-карту; на плате нужен профиль TERAK; рабочая версия — `AE82`.
[Полное описание профиля](../../docs/terak.md).

## Запись и проверка

Команды выполняются из этого каталога. Сначала проверить файлы:

```sh
shasum -a 256 -c SHA256SUMS
gzip -dk uj11-hc7000-terak.img.gz
```

Несжатый образ не хранится в Git; команда выше создаёт его из сжатой копии. Для записи выбирается **всё устройство SD**,
а не его раздел. Запись заменит прежнюю разметку и диски выбранной карты.
`diskN` и `sdX` ниже — заполнители, которые заменяются после определения SD.

macOS:

```sh
diskutil list external physical
diskutil unmountDisk /dev/diskN
sudo dd if=uj11-hc7000-terak.img of=/dev/rdiskN bs=1m
sync
sudo dd if=/dev/rdiskN bs=512 count=38912 2>/dev/null | shasum -a 256
diskutil eject /dev/diskN
```

Linux:

```sh
lsblk -o NAME,PATH,SIZE,MODEL,TRAN,RM,TYPE,MOUNTPOINTS
# Размонтировать разделы выбранной SD, затем:
sudo dd if=uj11-hc7000-terak.img of=/dev/sdX bs=4M conv=fsync status=progress
sudo dd if=/dev/sdX bs=512 count=38912 status=none | sha256sum
```

Перед первым запуском SHA-256 прочитанных 38 912 блоков должен быть:

```text
cd318474b099d7a12568c99098632edd77c3424b4d106daf26d44305222cbc11
```

После работы гостевой ОС карта может измениться: оба диска разрешают запись.
Видимый файл `TERAK.CFG` редактируется на FAT16; его копия рядом с образом
служит справкой. После редактирования размонтируйте карту до извлечения.

## Первый запуск

1. На HC7000 должна быть установлена прошивка `terak-ae82.jed` из этого комплекта.
2. Подключить PS/2-клавиатуру и видеоприёмник, поддерживающий 525/60.
3. Вставить записанную SD в выключенную плату, затем включить её.
4. Дождаться строки `Command: E(dit, R(un, F(ile, ...`, приветствия TERAK
   и `U.C.S.D. Pascal System II.0`.
5. Проверить клавиатуру клавишей F для входа в Filer.

Для разбора первого запуска сохранить сведения: маркировку SD, установленный
JED, наличие синхронизации видео, отображение меню и реакцию на F.
Если изображение отсутствует, отдельно проверить видеосинхронизацию и
загрузку SD. Сравнение прочитанной карты с SHA-256 выше исключает ошибку записи.

Полная проверка содержит 15 дисковых сценариев, включая QB с двойной
плотностью; их сводка сохранена в `checks/baseline-06b6.json`. Текущая проверка
MBR/raw, меню UCSD, PS/2 и смешанной плотности QB — `checks/functional-result.json`.
Эта первая аппаратная карта содержит два диска одинарной плотности.


На PCB800099-V.9 с RTD2660H штатное окно NTSC обрезало верхние строки.
Для проверенной прошивки дисплея два байта изменены: начало 26 → 18,
высота 232 → 240. Инструменты чтения, подготовки и записи через FT2232D
на VGA SDA/SCL находятся в `tools/rtd266x_*.py`; подробности и хеши —
[в описании профиля](../../docs/terak.md). Дампы прошивки дисплея в Git не включены.
Сборка AE82 передаёт все 640×240 точек при 60 полях/с;
полноценная ОС двойной плотности на железе ещё не проверялась.
