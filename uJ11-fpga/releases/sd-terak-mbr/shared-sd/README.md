# Проверенная общая SD

На физической общей карте сохранены диски Пълдина в разделах 2/3,
диски БК в логических разделах 5/6 и все 14 прежних файлов FAT16.
TERAK добавлен в логические разделы 7/8: UCSD II.0 и NASA DEM1,
каждый по 501 блоку SD. `TERAK.CFG` из этого каталога находится
в первом разделе FAT16 и назначает эти raw-диски приводам 0/1.

| Раздел | LBA | Блоков | Содержимое |
|---|---:|---:|---|
| 7 | 51200 | 501 | UCSD II.0, SSSD raw, RW |
| 8 | 55296 | 501 | NASA DEM1, SSSD raw, RW |

Запись и контрольное чтение O_DIRECT сохранены в `sd-written.json`.
Оператор подтвердил загрузку DOS-Shell БК с BIOS 2A29; результат —
`physical-bk-test.json`. TERAK AE82 проверен с этой же картой:
верхнее меню UCSD видно полностью, F открывает файловое меню.
Результат — `../qualification.json`, журнал записи FPGA — `../flash-session/`.

Образ `../uj11-hc7000-terak.img.gz` предназначен для отдельной карты
с TERAK в разделах 2/3. Конфигурации двух карт различаются.
