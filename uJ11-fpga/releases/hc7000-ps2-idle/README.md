# HC7000: PS/2 через аппаратное FIFO в свободные интервалы SERV

2026-10-02. JED **7CBA**, CPU 50 / PAL 64 МГц, MMU / FPP off / FIS /
SERV storage / PAL VT52 / PS/2. Клавиатура использует прежнее аппаратное FIFO
16 сканкодов с торможением CLOCK. Обработчик вызывается только из основного
цикла после дисков; `poll_io`, SPI/DMA и рисование его не вызывают.

MAP/PAR/TRACE и ограничения SRAM/CDC проходят. Ресурсы не изменились:
6046 LUT / 2098 FF / 26 EBR / 2 PLL; Fmax CPU 50,123 / PAL 65,733 МГц.
SERV: 16451 байт кода и констант, BSS 1080 байт, запас до стека 260 байт;
стек 640 байт, cold bank 512 байт, секторный буфер 512 байт.

Проверены приёмник/декодер, SERV/DL11/UART (39 байт), PAL
(157759 проверок, 2187 байт, 12 сдвигов). Каталог из 35 строк:
51165949 тактов / 1,023319 с, практически как E517 (1,023218 с).
Дисковый тест: 2475473 проверки, 24 чередующихся a/b/c после заполнения
очереди во время RL-read 5120 слов. Любые MMIO клавиатуры во время
дисковой команды запрещены проверкой. Данные прочитаны правильно, образ SD
не изменён; максимальные записи стека 336/640 байт. HC1200 production проходит.

Полный DIR через кадры PS/2 в первом прогоне вывел 214 файлов / 5346 блоков
без ошибки оверлея. Следующая UART-команда была усечена до SHOW без
аргумента: этот диагностический прогон сохранён как незавершённый.
Повторный прогон с ожиданием освобождения DL11 RBUF между байтами
UART-команд прошёл: **13039379 проверок, 485826386 тактов, 438282 DMA слов**.
Проверены загрузка XM, SHOW CONFIGURATION (1936 КБ), SHOW MEMORY, DM1 и
диски BASIC/Pascal/Fortran. PAL получил 3047 байт по порядку, стек 336/640.
Повторный прогон использует UART; кадры PS/2 и дисковый приоритет
подтверждены отдельными тестами выше.
Этот JED установлен на плату: FLASH Erase/Program/Verify прошла.
На прежней SD прошли RT-11 XM с RH0, полный DIR через UART и физическую
PS/2-клавиатуру (пользователь подтвердил PAL), конфигурация/память,
VOL: и диски компиляторов. RT-11 V4 с RK0 прочитала полный каталог и V4USER.TXT.
RSX с RQ1 завершила старт, прочитала RSX11M.SYS (1026 блоков) и остановлена
через SHUTUP с размонтированием DU1. BSD с RL0 перешла в multiuser/root,
смонтировала `/usr` на XP0h; по 1 МиБ с RL0/RL1/XP0h и ещё 2 МиБ с RL0
прочитаны без ошибок. Пользователь подтвердил PS/2 в BSD; захвачены
`ls -l /`, сборка `hello.c` штатным C-компилятором и запуск с выводом `hello`.
Ввод был после чтения дисков; одновременное заполнение FIFO на плате
не зафиксировано (этот случай проходит отдельный RTL-тест).
UART освобождён, плата оставлена в BSD на приглашении root.
Прежний сбой RL после длительного простоя пока
не считается устранённым. Аппаратные журналы: `validation/hardware/installed-7cba`.
Предыдущие аппаратные попытки с дисковыми ошибками сохранены в
[347F](../../history/releases/hc7000-ps2/README.md).
