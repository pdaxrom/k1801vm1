# RT-11FB для SD uJ11

`uj11-rt11fb.img.gz` — готовый комплект 2026-09-26.
Распакованный образ: **27 540 480 байт**, raw RK07 от сектора 0.
Записывать на всю карту SDHC/SDXC, без FAT/MBR и без смещения раздела.

[Состав, запись, запуск и воспроизведение](../../docs/sd-image.md).
Справка уже на диске: `TYPE SY:README.TXT`.

- `SHA256SUMS` — суммы raw и gzip.
- `manifest.json` — входы, SHA256 и размещение файлов.
- `directory.txt`, `image-info.txt` — полный каталог и геометрия.
- `validation.json`, `validation/` — результаты и журналы проверок.

Физическая SD не записывалась; проверенный raw для текущей сессии также
лежит в `build/sd-release/uj11-rt11fb.img`. Этот рабочий каталог не хранится в Git;
для восстановления raw достаточно распаковать опубликованный gzip.
