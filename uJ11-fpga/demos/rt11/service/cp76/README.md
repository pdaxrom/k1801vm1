# CP76: программный FP11-A с преобразованиями

Все документированные семейства FP11: управление, transfers, unary/compare,
ADD/SUB/MUL/DIV/MOD и преобразования F/D/I/L. **46 мнемоник / 3949 кодировок**.
Полные внешние diagnostics остаются отдельным этапом.
[Семантика, проверки и измерения](../../../../docs/fp11-conversions-cp76.md).
На физическую плату пакет ещё не установлен. Требуется существующая
**CP67b без MMU**; FPGA перепрошивать не требуется.

| Файл | Назначение |
|---|---|
| FP11.BIN | Absolute HALT module, BASE 040000, ABI3 / format2 |
| FP11.MAC | DEC MACRO-11 исходник, версия 00.09 |
| FPTST.SAV / FPTST.MAC | 43 FP STEP и самостоятельные проверки, версия 00.08 |
| release.json | SHA256, checksum, immutable length и полная аллокация |

Резерв **040000–050705**, всего **4550 байт** с BSS и стеком.
Checksum `105731` охватывает 4282 байта кода. BIN — 5120 байт,
10 блоков RT-11 с header. MEMEND=`050706`; 36410 байт свободны до
`160000`. Размещение абсолютное; BSS allocator и relocation отсутствуют.

Используется [UJMOD.SAV CP67](../cp67/UJMOD.SAV). Скопировать файлы на
RT-11 диск. `RUN UJMOD`, `STATUS` показывают таблицу модулей. Если FP уже
активен, выполнить `OFFn` для его слота и длинный RESET перед заменой.

```text
.RUN UJMOD
UJMOD> FP11
```

После длинного RESET без UART ESC bootstrap проверит checksum,
очистит FP-состояние и установит FP-ready; status=`140407`.
ODT/SDBOOT сохраняются. Для отключения: `OFFn`, затем cold RESET.
UART ESC в стартовом окне обходит все модули и выбирает встроенный bootstrap.

Проверка из холодного состояния: `RUN FPTST`, короткий RESET,
`R 7 1012`, **43 команды S**, затем `R 7 1220`, `C`.
Самопроверка заканчивается `RETURNED TO RT11`; проверяются MOD, D 1/3,
ошибки, границы I/L, округление LDCLF и carry STCfi.
Адреса действительны только для этого SAV; после пересборки смотреть
MAP/listing. Округление половины шага увеличивает модуль: LDCLF переводит
16777217 в 16777218. LONG immediate `#1` означает целое 65536.

ODT умеет выполнять FP по одному шагу, но дизассемблер пока показывает
`.WORD`. FP disassembly и просмотр AC/FPS/FEC/FEA остаются в TODO.

RT-11/UJMOD/ODT: **94 checks / 811627733 clocks / 9429 UART bytes — PASS**.
