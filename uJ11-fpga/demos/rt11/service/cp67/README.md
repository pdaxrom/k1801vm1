# CP67: модули FRAM

Пакет для **CP67b `--modules-cp67`**, без MMU. Требуется соответствующая FPGA
прошивка; на момент подготовки пакета физическая плата остаётся CP63b/CP66.
JED: [design.jed](../../../../synth/releases/cp67b/design.jed), SHA256
`d2e9000c47477c0ad8e8b4167338c74f274f2650dc46d8f1378446bb467e710d`.

| Файл | Назначение |
|---|---|
| UJMOD.SAV | Общий загрузчик/таблица модулей, RT-11 |
| UJMOD.MAC | Собираемый DEC MACRO-11 исходник загрузчика с HALT helper |
| ODT.BIN | Самоинициализирующийся UART/HDSP ODT, абсолютный BASE `010000` |
| SDBOOT.BIN | Простой заменяемый bootstrap, абсолютный BASE `006000` |
| release.json | SHA256 доставляемых файлов |

Скопировать UJMOD.SAV и оба BIN на системный диск RT-11. Старые UJLOAD/UJON
не используются для ABI3. Запустить:

```text
.RUN UJMOD
UJMOD> ODT
!UJMOD-I-DONE; long RESET without ESC initializes enabled modules
.RUN UJMOD
UJMOD> SDBOOT
!UJMOD-I-DONE; long RESET without ESC initializes enabled modules
```

Сделать длинный RESET. Без ESC ROM проверит оба образа, вызовет инициализаторы
и запустит RT-11. Короткий RESET после этого входит в ODT, повторный UJON
не нужен. После длинного RESET начинается новый сеанс отладки; старую USER
программу следует загрузить заново. Для пульта общие JTAG-пины должны быть
переведены в GPIO, как в CP66.

`RUN UJMOD` → `STATUS` выводит восемь строк:
`номер: BASE LENGTH CHECKSUM STATUS`. Числа восьмеричные, LENGTH в словах.
При установке на пустую таблицу ODT занимает запись 0, SDBOOT — запись 1;
повторная загрузка с тем же BASE заменяет прежнюю запись.

`OFF0`..`OFF7` выключает автозапуск записи, сохраняя размещение.
`DEL0`..`DEL7` удаляет запись, не стирая её код. Живые службы выключаются
до изменения таблицы; обычный холодный RESET включает оставшиеся модули заново.

Для восстановления сделать длинный RESET и отправить **UART ESC после его
отпускания**, в течение примерно двух секунд. Допустима повторная отправка.
Все FRAM-модули будут обойдены и выполнится встроенный bootstrap, даже если
расширенный загрузчик имеет правильную сумму, но зависает. После загрузки
RT-11 можно удалить или заменить неисправную запись через UJMOD.

Образы пока не relocatable. Формат четырёх полей таблицы допускает будущий
загрузчик с relocation records, но эта версия загружает по адресу сборки.
[Подробный контракт и проверки](../../../../docs/retained-modules-cp67.md).
