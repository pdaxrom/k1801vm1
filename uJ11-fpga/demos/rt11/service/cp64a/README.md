# CP64a: граница прокрутки ODT

Исправлена прокрутка короткого результата после длинной строки: `>` больше
не читает остатки текста за завершающим NUL. Изменение занимает **6 байт**;
полный ODT — **8416 из 12288 байт HALT FRAM**, payload 7632 байта.

Использовать **оба** файла этой сборки: `ODT.BIN` и `UJON.SAV`.
`release.json` содержит SHA256. Старая пара сохранена в [CP64](../cp64/).
Требуется прежняя FPGA **CP63b**; JED, RTL и микрокод не менялись.

После копирования обоих файлов на системный диск загрузить их из RT-11:

```text
RUN UJLOAD
ODT
RUN UJON
```

Загрузчик — прежний [CP62 UJLOAD.SAV](../cp62/UJLOAD.SAV). Для клавиатуры
освободить общие пины от JTAG; после холодного старта повторить загрузку
и включение. [Команды](../../../../docs/odt-cp64.md),
[проверки CP64a](../../../../docs/odt-cp64a.md),
[состояние реальной платы](../../../../docs/board-bringup-cp64.md).
