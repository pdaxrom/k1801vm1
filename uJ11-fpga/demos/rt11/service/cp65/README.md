# CP65: программный ODT для пульта и UART

Автопрокрутка HDSP туда-обратно, PREV/NEXT по командам, горячие клавиши 8–F,
просмотр одного регистра на панели и программный STEP OVER. UART `R`
сохраняет немедленный вывод всех регистров.

FPGA остаётся **CP63b**; добавлено **0 LUT / 0 FF / 0 EBR**.
Программа с данными и стеком занимает **9902 из 12288 байт HALT FRAM**.
Загружать согласованную пару `ODT.BIN` / `UJON.SAV` из этой директории;
SHA256 записаны в `release.json`. Прежний загрузчик —
[CP62 UJLOAD.SAV](../cp62/UJLOAD.SAV). После копирования файлов на системный диск:

```text
RUN UJLOAD
ODT
RUN UJON
```

Короткий RESET входит в ODT. После холодного старта загрузку и включение
нужно повторить. Для клавиатуры освободить общие пины от JTAG.

8 — STEP IN, 9 — STEP OVER, A — регистры, B — память, C — дизассемблер,
D — адрес GO, E — CONTINUE, F — OCT/HEX. При числовом вводе HEX кнопки
8–F служат цифрами. STEP OVER выполняется циклом одиночных шагов,
откладывает IRQ/trace, имеет отмену и предел; это не RUN до аппаратной точки.

[Команды, ограничения и проверки](../../../../docs/odt-cp65.md).
`UJTEST.MAC` — стендовая программа с намеренно нечётным SP под IPL7,
не программа для обычного запуска пользователем.
