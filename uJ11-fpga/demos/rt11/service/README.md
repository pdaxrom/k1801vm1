# UJLOAD: установка служб в верхнюю FRAM

`UJLOAD.SAV` — готовая программа RT-11FB V05.03, собранная оригинальными
MACRO/LINK из `UJLOAD.MAC`. Размер файла — 7 блоков (3584 байта);
код и данные занимают 2960 байт, начальный адрес `001000`.
SHA-256: `07e423df0e2f6f7798834979b8c99b3cc236b0affe25e998ad8424e6c019b723`.

Минимальный аппаратный ABI — CP58 SEL004; рабочий профиль — CP60b с
исправленным возвратом RT-11 после ошибок чтения SD.
На установленном CP56a служебных инструкций ещё нет. Полные ODT и FP11
запланированы отдельно; их готовых файлов в этом каталоге нет.
FIS остаётся в микрокоде.

Из корня `uJ11-fpga` можно создать отдельную копию RT-11 с загрузчиком:

```sh
python3 tools/build_service_disk.py --output build/rt11-ujload.dsk
```

После появления настоящих модулей ABI1 добавлять их опцией
`--module path/ODT.BIN --module path/FP11.BIN`. Скрипт проверяет формат,
контрольные суммы и совпадение файлов после извлечения из диска.
Исходный образ сохраняется; существующий выходной файл не перезаписывается.
На настоящем носителе файлы можно скопировать обычными средствами RT-11
в `SY:`, например через уже работающий HG.

```text
.RUN UJLOAD
UJLOAD> STATUS
ODT=0 FP11=0

.RUN UJLOAD
UJLOAD> ODT
```

Команда `ODT` загружает `SY:ODT.BIN`, `FP11` — `SY:FP11.BIN`.
`OFFODT`/`OFFFP` независимо отключают службы, `EXIT` выходит.
Каждый запуск принимает одну команду. После cold reset обе службы нужно
загрузить заново: сохранившееся содержимое FRAM само не активируется.

[Формат файлов, последовательность установки и ограничения](../../../docs/service-loader-cp60.md).
Тестовые обработчики генерируются только в `build/cp60-loader`; это
заготовки для проверки входа/возврата, а не монитор и эмулятор FP11.

Пересборка оригинальными инструментами требует `pdp11` (SIMH),
`lsi11/rt11tool` и исходного диска `lsi11-fpga/images/rt11v503.dsk`:

```sh
python3 tools/rt11_build.py demos/rt11/service/UJLOAD.MAC --out build/ujload-new
```

Используется только новая рабочая копия диска; `microasm11` не нужен.
