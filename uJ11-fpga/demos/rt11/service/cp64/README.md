# CP64 ODT

Требуется FPGA **CP63b** (`--debug-cp63`). Плата CP56a этого ABI не поддерживает.

Готовые `ODT.BIN` и `UJON.SAV` должны быть одной сборки; контрольные суммы
зафиксированы в `release.json`. Загрузка — прежним
[CP62 UJLOAD.SAV](../cp62/UJLOAD.SAV):

```text
.RUN UJLOAD
UJLOAD> ODT
.RUN UJON
```

Затем короткий RESET входит в ODT, длинный выполняет аппаратный reset.
`H` — команды UART, MEM — меню пульта. Панельные команды и результаты
автоматически печатаются на UART. После cold reset требуется новая установка
UJLOAD/UJON. После любой смены ready старым UJLOAD повторить UJON.

`UJTEST.MAC` — направленный тест, не монитор. Он временно использует нечётный
SP под IPL7 и намеренно не завершается без команды отладчика; не запускать
для обычной работы. Готовый UJTEST.SAV находится только в test archive.
