# CP77: ODT с FP11 и FP11-A по новому адресу

**Только программные модули FRAM; FPGA перепрошивать не требуется.**
На плату пакет пока не устанавливался.
[Команды, память, проверки и ограничения](../../../../docs/odt-fp-cp77.md).

- `ODT.BIN`: base `010000`, весь диапазон с BSS/stack до `042544` (exclusive).
- `FP11.BIN`: base `060000`, до `070720` с BSS/stack.
- `FPTST.SAV`: прежняя native FP-самопроверка CP76; 43 шага ODT.
- `UJMON.MAC`, `FP11.MAC`, `FPTST.MAC`: точные исходники собранных файлов.

ODT и FP11 — абсолютные модули ABI3 / format2. **Нельзя устанавливать ODT
CP77 поверх ещё зарегистрированного FP11 CP76 на `040000`: области
пересекаются.** Старый пакет CP76 сохранён отдельно для воспроизведения.

## Установка через существующий UJMOD

Скопировать файлы пакета на рабочий диск RT-11 принятым способом HG/hostdisk.
`SDBOOT.BIN` и `UJMOD.SAV` остаются из CP67. Номера слотов сначала узнать
через `RUN UJMOD` → `STATUS`; каждый вызов UJMOD возвращается в RT-11.

Если FP11 ещё не установлен (текущее подтверждённое состояние платы):

1. `RUN UJMOD` → `ODT` заменяет прежний ODT в его слоте.
2. `RUN UJMOD` → `FP11` регистрирует новый модуль по `060000`.
3. Проверить `STATUS`, затем выполнить длинный RESET без ESC.

Если установлен старый FP11 по `040000`:

1. Через `STATUS` определить **его** слот; `RUN UJMOD` → `DELn` удаляет
   старую запись. `OFFn` недостаточно: он сохраняет размещение.
2. `RUN UJMOD` → `FP11` устанавливает новую версию по `060000`.
3. `RUN UJMOD` → `ODT` заменяет ODT, затем проверить `STATUS`.
4. Длинный RESET без ESC запускает самоинициализацию обоих модулей.

Не выбирать номер слота по примеру вслепую. DEL не стирает байты, но после
удаления записи старый FP не должен активироваться. Каждая загрузка UJMOD
отключает сервисы до cold init; не проверять FP/ODT между шагами обновления.
Полные размещения модулей с BSS пока резервируются вручную.

После загрузки короткий RESET открывает ODT. `F` печатает AC0–AC5,
FPS/FEC/FEA. На пульте MEM → FP REGISTERS → ENTER; PREV/NEXT/ENTER
листают один регистр за раз. `F 10` показывает FEA при восьмеричном вводе.

Для FPTST: `RUN FPTST`, короткий RESET, `R 7 1012`, затем 43 команды `S`.
Остановившись на `001216`, задать `R 7 1220` и `C`: программа проверит
результаты и напечатает `!FPTST-I-RETURNED TO RT11`. Это значения именно
вложенной FPTST 00.08; не использовать их для другой сборки.

Все три DEC FP11-A части проходят в RTL-стенде с test-only чтением PSW.
Рабочая CP67b ещё не имеет memory-mapped PSW `177776`, поэтому запуск этих
образов на плате как неизменённых standalone diagnostics пока не заявляется.
