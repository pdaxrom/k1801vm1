# CP69: адресация FP11 и STST

Тестовый пакет для CP67b без MMU. Поддержаны CFCC, SETF/SETD, SETI/SETL
и все режимы LDFPS/STFPS/STST — 8 мнемоник / 197 кодировок.
**Арифметики и LDF/STF пока нет.** Остальные FP opcode формируют FEC=2
с учётом FID. [Полный контракт и тесты](../../../../docs/fp11-memory-cp69.md).
На физическую плату этот пакет пока не установлен.

| Файл | Назначение |
|---|---|
| FP11.BIN | Самоинициализирующийся модуль ABI3, BASE 040000 |
| FP11.MAC | DEC MACRO-11 исходник модуля, версия 00.02 |
| FPTST.SAV / FPTST.MAC | RT-11 программа для пошаговой проверки через ODT |
| release.json | SHA256, размер и граница реализованной ISA |

Используется прежний [UJMOD.SAV CP67](../cp67/UJMOD.SAV). FP11 занимает
HALT **040000..041665, 950 байт**, включая данные и stack. Образ абсолютный.
Другие модули не должны занимать этот диапазон: checksum покрывает только
734 байта кода. FP11.BIN — три RT-11 блока. FPGA перепрошивать не требуется.

После копирования FP11.BIN и FPTST.SAV на системный диск RT-11:

```text
.RUN UJMOD
UJMOD> STATUS
.RUN UJMOD
UJMOD> FP11
```

Длинный RESET без UART ESC проверяет checksum и активирует модуль.
При успешном cold init статус записи становится `140407`.
FPS/FEC/FEA и AC очищаются при каждом cold reset, ODT/SDBOOT сохраняются.
В проверенной тестовой таблице ODT/SDBOOT/FP11 занимают записи 0/1/2;
номер существующего модуля нужно брать из STATUS. При замене прежнего FP11
сначала выключить его через `OFFn` и cold RESET, затем установить новый файл.

Для отключения: `OFFn` через UJMOD и длинный RESET. UART ESC в начальном
окне загрузки выбирает встроенный bootstrap и пропускает все FRAM-модули.

`RUN FPTST` печатает CONTROL TEST и выполняет контрольную последовательность,
затем остаётся в BR loop. Короткий RESET открывает ODT. Командой `R 7 1012`
установить начало последовательности, затем исполнить восемь `S`:

1. SETD — FPS=`200`.
2. SETL — FPS=`300`.
3. STFPS STATUS — USER[`001132`]=`300`.
4. MOV #BUF,R2 — R2=`001134`.
5. LDFPS #40000 — FPS=`40000`.
6. Неподдержанная `170003` — FPS=`140000`, FEC=2, FEA=`001032`; FID подавляет trap.
7. STST (R2)+ — USER[`001134`]=2, USER[`001136`]=`001032`, R2=`001140`.
8. STFPS R1 — R1=`140000`, PC=`001040`.

Продолжение: `R 7 1042`, затем `C`. FPTST проверяет сохранённые значения,
печатает RETURNED TO RT11 и завершает работу; при ошибке печатает STATE MISMATCH.
Это адреса данного FPTST.SAV, проверенные по DEC MAP/LST и UART regression.
ODT пока выводит FP opcode как `.WORD`, хотя STEP выполняет их полностью.

Полный сценарий установки, STEP, возврата, DIR, повторного RESET и OFF
прошёл в модели CP67b со SPI SD/FRAM и UART waveform: 33 проверки — PASS.
Это ещё не аппаратная проверка установленного FP11-модуля.
