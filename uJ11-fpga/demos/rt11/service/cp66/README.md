# CP66: ODT.BIN и UJON.SAV

Согласованная пара программ для **FPGA CP63b**, без перепрошивки FPGA.
Четыре программные точки, RUN TO, STEP OVER с обычными IRQ и прежний пульт
с автопрокруткой. [Команды и ограничения](../../../../docs/odt-cp66.md).

Оба файла нужно заменить вместе. UJON проверяет код и контрольную сумму
конкретного ODT; активатор от другой сборки не подходит. Надпись активатора
`CP64 DEBUG ENABLED` — историческое имя протокола проверки, а не версия
монитора. На входе новый монитор печатает `UJ11 ODT CP66:`.

После копирования файлов на SD через RT-11 и проверки обратного чтения:

```text
RUN UJLOAD
ODT
RUN UJON
```

ODT вводится в приглашении UJLOAD. Затем короткое нажатие RESET открывает
монитор; 9 на панели — новый STEP OVER. Если выполняется старый сеанс с
точками, сначала Z и C; не заменять ODT поверх активных патчей. При cold reset
заново загрузить отлаживаемую программу и ODT/UJON, затем задать точки.

Меню MEM содержит SET/CLEAR/LIST/OFF для точек и RUN TO ADDRESS.
Тот же интерфейс UART: `P addr`, `Z addr`, `P`, `Z`, `U addr`.
T/U выполняются до цели либо короткого RESET. Для прежнего ограниченного
STEP-цикла с отложенными IRQ явно задать `T limit`.

`UJTEST.MAC` — нативная программа полного RTL-теста: вложенные вызовы,
WAIT/KW11-L и LOOKUP/READW/CLOSE файла ODT.BIN. Она не устанавливается
автоматически вместе с монитором.

После фиксации программного архива CP66 установлен на плату. SD-файлы
проверены обратным чтением, ODT READY и debug enabled подтверждены.
[Журнал установки и границы аппаратной проверки](../../../../docs/board-bringup-cp66.md).

Финальная сборка прошла 112 breakpoint, 187 core, 2699 panel checks и полный
RT-11/FRAM прогон: 296 проверок, 514657090 тактов. [Сводка](../../../../docs/verification-cp66.json).
ODT занимает 11746 из 12288 байт HALT FRAM; FPGA не менялась.
