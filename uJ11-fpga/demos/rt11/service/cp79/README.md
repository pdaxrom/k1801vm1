# CP79: программный FPP J‑11 и ODT

FP11.BIN 00.11 — программная эмуляция FPP DCJ11 в HALT FRAM.
**FPGA перепрошивать не требуется. На плату пакет пока не установлен.**
[Профиль, источники DEC и проверки](../../../../docs/fpp-j11-cp79.md).

| Файл | Назначение |
|---|---|
| FP11.BIN / FP11.MAC | FPP J‑11; base 060000, BSS/stack до 070646 exclusive |
| ODT.BIN / UJMON.MAC | ODT CP77, побайтно прежний; 010000–042544 exclusive |
| FPTST.SAV / FPTST.MAC | Самопроверка J‑11 00.09, работающая через RT‑11 |
| release.json | Размеры, checksum модулей, SHA256 всех файлов |

Модули абсолютные, CP67 ABI3 / format2; BSS/stack резервируется вместе
с кодом. SDBOOT.BIN и UJMOD.SAV используются из пакета CP67.

Передать файлы через имеющийся HG/hostdisk. Через `RUN UJMOD` → `STATUS`
посмотреть реальные слоты и адреса. Если FP11 уже находится на 060000,
`RUN UJMOD` → `FP11` заменяет его. Если FP11 ещё не установлен, та же
команда создаёт запись. Затем установить `ODT` и выполнить длинный RESET
без ESC: оба модуля проверят checksum и самоинициализируются.

Если в таблице ещё есть прежний FP11 на 040000, сначала удалить именно
его запись через DELn (номер узнать через STATUS): иначе расширенный ODT
пересекается с его размещением. OFFn сохраняет размещение и здесь
не заменяет DELn. Между загрузкой модулей и cold init FP/ODT не проверять.

Короткий RESET открывает ODT. UART `F` показывает AC0–AC5/FPS/FEC/FEA;
пульт MEM → FP REGISTERS → ENTER показывает по одному регистру.
Адреса состояния FPP ODT получает из descriptor, они не зашиты в монитор.

Самопроверка: `RUN FPTST`, короткий RESET; `R 7 1012`, затем 43 команды
`S`. На 001216 задать `R 7 1220`, затем `C`. Ожидается
`!FPTST-I-RETURNED TO RT11`. Адреса относятся именно к вложенной FPTST
00.09; для других сборок пользоваться MAP/listing.

У CP79 TST/ABS/NEG над memory −0 при FIUV отменяются до выполнения.
Поэтому FPTST и ожидаемые FPS отличаются от старого пакета FP11-A.
Рабочая CP67b пока не реализует CPU-local PSW 177776; соответствующие
MMIO-операнды и внешняя полная J‑11 диагностика остаются в TODO.
