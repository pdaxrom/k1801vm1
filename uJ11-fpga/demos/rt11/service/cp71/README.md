# CP71: FP11-A unary и compare

Пакет для аппаратуры CP67b без MMU. Поддерживает управляющие команды,
LDF/LDD/STF/STD и **CLR/TST/ABS/NEG/CMP в F/D**, все addressing modes.
ADD/SUB/MUL/DIV и преобразований ещё нет.
[Контракт, отличие TST FP11-A от J-11 и проверки](../../../../docs/fp11-unary-cp71.md).
На физическую плату пакет не установлен; FPGA перепрошивать не нужно.

| Файл | Назначение |
|---|---|
| FP11.BIN | Absolute HALT module, BASE 040000, CP67 ABI3 |
| FP11.MAC | DEC MACRO-11 исходник, версия 00.04 |
| FPTST.SAV / FPTST.MAC | RT-11 тест результата и одиннадцати STEP в UART ODT |
| release.json | Hashes, immutable length, полная аллокация |

FP11 занимает **040000–043071, 1594 байта** HALT FRAM с BSS/stack.
Checksum покрывает 1364 байта кода; файл — четыре RT-11 блока.
Другие модули не должны пересекать весь диапазон до MEMEND=`043072`.
Relocation и автоматического размещения BSS пока нет.

Использовать [UJMOD.SAV CP67](../cp67/UJMOD.SAV). После копирования файлов
на системный диск выполнить `RUN UJMOD`, `STATUS`. Если FP11 уже активен,
сначала `OFFn` и длинный RESET. Индекс n брать из STATUS. Затем:

```text
.RUN UJMOD
UJMOD> FP11
```

После следующего длинного RESET без UART ESC модуль проходит checksum,
очищает FPS/FEC/FEA/AC и включает FP-ready. Статус записи — `140407`.
ODT/SDBOOT сохраняются. Для отключения — `OFFn` и cold RESET.
UART ESC в начальном окне выбирает встроенный bootstrap и пропускает все
FRAM-модули. В тесте FP11 находится в записи 2.

`RUN FPTST` печатает заголовок теста, выполняет операции и остаётся в BR loop.
Короткий RESET открывает ODT. Установить `R 7 1012`, выполнить одиннадцать `S`.
В первых семи строках ниже указан `FPS & 217`: FD/NZVC без сохраняемых
error/mode bits. В шагах 8–11 значения FPS полные:

| Шаг | Команда | Проверяемый результат |
|---:|---|---|
| 1 | SETD | FD=1; прежние NZVC сохраняются (после cold init FPS=`200`) |
| 2 | LDD SOURCE,AC2 | AC2=`040200,012345,065432,023456` |
| 3 | NEGD AC2 | Первое слово AC2=`140200`, FPS=`210` |
| 4 | ABSD AC2 | Первое слово AC2=`040200`, FPS=`200` |
| 5 | CMPD SOURCE,AC2 | Равенство, FPS=`204`; AC2 прежний |
| 6 | TSTD AC2 | FPS=`200` |
| 7 | CLRD AC5 | Все четыре слова AC5=0, FPS=`204` |
| 8 | LDFPS #44000 | FIUV и FID включены, FPS=`44000` |
| 9 | TSTF MINUS | FP11-A ставит FPS=`144014`, FEC=`14`, FEA=`001040` |
| 10 | STFPS RESULT | USER `001214`=`144014` |
| 11 | STST ERR | USER `001216/001220`=`14/001040` |

После этого PC=`001054`. Продолжение: `R 7 1056`, затем `C`.
FPTST проверяет FPS/error registers, сохраняет AC2 в BACK (`001222–001230`),
сверяет его с SOURCE (`001200–001206`), проверяет нулевой AC5 через ZERO
(`001232–001240`) и печатает RETURNED TO RT11. При несовпадении — STATE MISMATCH.
Адреса относятся именно к приложенному FPTST.SAV.

ODT пока показывает FP opcode как `.WORD`; STEP выполняет команду целиком.
AC проверяются FPTST и моделью. Пользовательской команды dump AC/FPS/FEC/FEA
в ODT пока нет. Повторный STEP допустим: LDD заново задаёт AC2, а LDFPS #44000
сбрасывает предыдущий FER. Автоматический тест останавливает FPTST до первой
FP-команды после cold init и дополнительно проверяет полный FPS первых шагов.

Полный сценарий UJMOD, STEP, проверки самой FPTST, DIR, cold reset и OFF
прошёл в симуляции CP67b со SPI SD/FRAM и UART waveform: **43 checks / 531033015 clocks / 3476 UART bytes — PASS**.
Аппаратная установка остаётся отдельной проверкой.
