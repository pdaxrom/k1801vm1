# CP80: PSW-операнды программного FPP J‑11

FP11.BIN **00.12**, base **060000**, размещение **4614 байт** до
**071006** exclusive. Модуль абсолютный, format2 / CP67 ABI3.
Операнды 177776 читают/пишут сохранённый USER PSW; T защищён,
флаги FPS и CPU учитываются раздельно.
[Реализация, тесты и ограничения](../../../../docs/fpp-psw-cp80.md).

**FPGA перепрошивать не требуется. CP80 на плату пока не установлен.**

Включены FP11.BIN/FP11.MAC, прежние ODT.BIN/UJMON.MAC CP77,
FPTST.SAV/FPTST.MAC и release.json с SHA256. SDBOOT.BIN и UJMOD.SAV
используются из CP67. ODT получает новые адреса состояния FPP через
descriptor на 060010, замена его кода не требуется.

Установка вместо текущего CP79:

1. Передать FP11.BIN через HG на диск RT‑11, проверить readback.
2. `RUN UJMOD` → `STATUS`: убедиться, что слот FP11 размещён на 060000.
3. Команда `FP11` заменяет существующий модуль; `STATUS` проверяет запись.
4. Длинный RESET без ESC: модули проверят checksum и самоинициализируются.
5. Короткий RESET → ODT, команда `F` показывает новое состояние FPP.

Не использовать FP/ODT между заменой модуля и cold init: адреса BSS
поменялись. Остальные занятые области HALT FRAM должны оставлять свободный
диапазон 060000–071006. UJMOD проверяет размещение по дескрипторам модулей.

FPTST 00.09 сохранён: это прежняя общая регрессия 43 FP-шагов, а не
самостоятельная аппаратная проверка новых PSW-случаев. Последние пока
квалифицированы RTL-стендами CP80; физическая проверка CP80 ещё требуется.
Обычные integer-обращения к PSW 177776 этим пакетом не добавляются.
