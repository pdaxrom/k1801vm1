# CP70: перенос FP11 в форматах F/D

Пакет для аппаратуры CP67b без MMU. FP11 firmware поддерживает управляющие
команды CP69 и **LDF/LDD, STF/STD**, все addressing modes и AC0–AC5.
Арифметики, преобразований и остальных FP-команд пока нет.
[Контракт и ограничения](../../../../docs/fp11-transfers-cp70.md).
На физическую плату этот пакет пока не установлен; FPGA перепрошивать не нужно.

| Файл | Назначение |
|---|---|
| FP11.BIN | Absolute HALT module, BASE 040000, CP67 ABI3 |
| FP11.MAC | DEC MACRO-11 исходник, версия 00.03 |
| FPTST.SAV / FPTST.MAC | RT-11 проверка F/D и AC через UART ODT |
| release.json | Hashes, immutable length и полная аллокация |

FP11 занимает **040000–042341, 1250 байт** HALT FRAM, включая BSS/stack.
Checksum покрывает 1022 байта кода. Модульный файл занимает три RT-11 блока.
Другие модули не должны пересекать весь диапазон до MEMEND=`042342`.
Relocation и автоматического размещения BSS пока нет.

Использовать [UJMOD.SAV CP67](../cp67/UJMOD.SAV). После копирования файлов
на системный диск сначала `RUN UJMOD`, `STATUS`. Если FP11 уже активен,
выключить его командой `OFFn` и выполнить длинный RESET. Затем:

```text
.RUN UJMOD
UJMOD> FP11
```

После следующего длинного RESET без UART ESC модуль проходит checksum,
очищает FPS/FEC/FEA/AC и включает FP-ready. Ожидаемый статус записи — `140407`.
ODT/SDBOOT сохраняются. Индекс n брать из STATUS; в тесте FP стоит в записи 2.
Для отключения — `OFFn` и cold RESET. UART ESC в начальном окне выбирает
встроенный bootstrap и пропускает все FRAM-модули.

`RUN FPTST` печатает TRANSFER TEST, выполняет переносы и остаётся в BR loop.
Короткий RESET открывает ODT. Установить `R 7 1012`, затем выполнить десять `S`:

| Шаг | Команда | Проверяемый результат |
|---:|---|---|
| 1 | SETD | FPS=`200` |
| 2 | LDD SOURCE,AC2 | AC2=`040600,012345,065432,023456` |
| 3 | STD AC2,AC5 | AC5 получает все четыре слова |
| 4 | SETF | FPS=0 |
| 5 | LDF #1.0,AC2 | AC2=`040200,0,065432,023456`: младшие слова сохранены |
| 6 | STF AC2,FRES | USER `001204/001206` = `040200/0` |
| 7 | SETD | FPS=`200` |
| 8 | STD AC2,DRES | Четыре слова AC2 в USER `001210–001216` |
| 9 | LDD AC5,AC1 | AC1 получает исходные четыре слова SOURCE |
| 10 | STD AC1,BACK | USER `001220–001226` равны SOURCE `001174–001202` |

После этого PC=`001050`. Продолжение: `R 7 1052`, затем `C`.
FPTST проверяет FRES/DRES/BACK и печатает RETURNED TO RT11; при несовпадении
печатает STATE MISMATCH. Адреса относятся именно к приложенному FPTST.SAV.
ODT пока показывает FP opcode как `.WORD`; STEP выполняет команду целиком.
AC проверяются тестовой программой и моделью, отдельной команды dump AC
в пользовательском ODT пока нет.

Полный сценарий установки, STEP, проверки FPTST, DIR, cold reset и OFF
прошёл в симуляции CP67b со SPI SD/FRAM и UART waveform:
**48 checks / 521238827 clocks — PASS**. Аппаратная установка остаётся отдельно.
